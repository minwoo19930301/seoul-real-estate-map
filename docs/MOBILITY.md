# 사람 1인칭과 정적 크기 비교 모형

**사람 1인칭**은 주변 원본 길에서 추정 지면 위 약 **1.7m**로 보는 카메라 모드입니다. 사용자가 앞뒤·회전 버튼을 눌러 시점을 움직입니다. 자동으로 걷는 사람, 달리는 차량, 땀 효과와 이동 시뮬레이션은 제거했습니다. 일반 지도에서는 최대 줌까지 확대해도 사람·차량 모형을 표시하거나 이 기능의 경로를 조회하지 않습니다.

설정의 **거리 크기 가늠하기 → 사람 1인칭 예시**는 높이 기록이 있는 주변 건물과 길을 볼 수 있는 **행당동**으로 이동합니다. 기준 위치는 경도 127.03911815·위도 37.561191125, 방향은 350.39°입니다. 실제 카메라는 가까운 원본 길에 맞춥니다.

## 카메라와 조작

가까운 보행로를 우선해 지면 높이를 확인한 뒤 진입합니다. 앞뒤 버튼은 바라보는 방향에 맞춰 같은 길을 따라 3m씩 이동하고, 좌우 버튼은 15°씩 회전합니다. 길 끝을 넘어 가상 경로를 만들지 않습니다. 건물 실내·교량 상판·실제 보행 안전을 안내하는 기능은 아닙니다.

1인칭에서는 지형을 **1배**로 표시하고 배율·기울기 조절을 잠급니다. 명시적인 **지도 시점** 버튼은 진입 전 카메라와 2D/2.5D 모드·강조 배율을 복원합니다. 2D/2.5D 버튼은 현재 위치·줌을 유지하며 보기 방식만 바꿉니다. 진입을 다시 시도하면 그 요청 직전 시점을 새 복귀 위치로 저장하고, 실패해도 그 위치를 보존합니다.

드래그·휠·지도 확대 버튼·외부 카메라 API를 조작하면 길 고정 추적을 해제하고 정적 비교 모형도 숨깁니다. 이때 현재 카메라·지형 1배·지면 고정 정책을 다시 설정하지 않아 사용 중인 확대 동작을 되돌리지 않습니다. 자동 모형 표시를 다시 시작하는 줌 경계는 없습니다.

지도는 최대 줌 **24**, 기울기 **85°**를 허용합니다. 1인칭 예시는 기울기 82°를 사용하며 실제 줌은 화면 높이와 시야각에 따라 달라집니다. 특정 줌 숫자를 사람 눈높이로 간주하지 않습니다.

카메라는 현재 렌더링된 추정 지면에 1.7m를 더해 설정합니다. 공개 `calculateCameraOptionsFromTo`와 카메라 값·`queryTerrainElevation`으로 지면과의 높이 차이를 확인합니다. 지형 조회값은 이미 화면 강조 배율이 반영된 값이므로 다시 곱하지 않습니다. 늦게 도착한 지형이 지면을 바꾸면 `setCenterElevation`으로 수직 차이만 보정하며 줌·중심·회전을 되돌리지 않습니다. 실측 기준의 눈높이 정확도를 보증하는 값은 아닙니다.

## 고정 크기 비교 모형

**1인칭 크기 비교 모형 표시**는 기본으로 켜져 있습니다. 1인칭 진입에 성공했을 때만 주변 실제 보행로·차도에 **최대 사람 1개·승용차 1개**의 고정 예시를 배치합니다. 화면에서 사용할 수 있는 원본 길과 가림 조건에 따라 일부 또는 전부가 없을 수 있으며, 없는 길에 대체 모형을 만들지 않습니다. 실제 사람·차량 위치나 주차 상태를 뜻하지 않습니다.

| 모형 | 높이 | 폭 | 길이 |
|---|---:|---:|---:|
| 사람 | 1.7m | 0.5m | 0.3m |
| 승용차 | 1.5m | 1.8m | 4.3m |

이 치수는 크기를 가늠하기 위한 설정값입니다. 최초 배치 이후 같은 1인칭 장면에서 앞뒤 이동·회전·표시 토글을 해도 모형의 세계 좌표는 고정됩니다. 시점이 바뀌면 화면상의 위치와 크기만 달라집니다. 모드에서 나가거나 자유 시점으로 전환하면 배치를 비웁니다.

모형은 진입 때 카메라가 받은 경로 자료를 재사용하며 자체 `fetch`, RAF, 타이머, 지도 `triggerRepaint` 루프가 없습니다. 지도 렌더링에 맞춰 필요한 캔버스만 다시 그립니다. 정지한 화면에서는 시간이 흘러도 위치·보행 자세가 바뀌지 않습니다.

발·차량 바닥은 공개 `map.project`로 현재 렌더링된 지면에 맞춥니다. 몸체는 현재 지형 높이와 공개 투영 행렬로 미터 치수를 투영합니다. 지형 역투영과 일반 건물 화면 hit로 가려진 앵커를 보수적으로 제외합니다. 이는 별도 캔버스이며 지도 WebGL의 깊이 버퍼를 공유하지 않습니다. 몸 전체의 정확한 가림이나 **Blender GLB 모형의 깊이 가림**은 지원하지 않습니다.

## 경로·고도와 조회 범위

`/api/mobility?bbox=west,south,east,north`라는 기존 API 경로는 **사용자가 1인칭에 진입할 때 주변 길을 찾는 용도**로 남아 있습니다. 로컬 `roads.sqlite`의 원본 선과 보간 지형을 사용하며, 교량·터널·고가·에스컬레이터·접근 제한 경로를 제외합니다. 차량 역방향 일방통행(`oneway=-1`)은 원래 경로 방향에 반영합니다. 실제 인도 자료가 없는 곳에 임의 보행로를 만들지 않습니다.

지형 고도는 Terrain-RGB 타일과 유효 마스크로 확인합니다. 쌍선형 보간의 네 이웃 픽셀과 표본 사이 선분의 지원 픽셀 범위를 검사하고, 결측 구간을 0m로 채우거나 연결하지 않습니다. 경로를 최대 12m 간격으로 나누되 원본 꺾임은 유지합니다. 이 값은 등고선·표고점 사이의 **보간 결과**이며 개별 계단 실측 높이나 도로 설계 경사가 아닙니다.

서버는 가로·세로 2.2km 이내의 요청에 최대 60개 경로를 반환합니다. 경로당 750m·180점, 전체 샘플 18,000개, 후보 320개 등의 한도를 두며 응답의 `truncated`로 선택 제한을 알립니다. 이 기능은 전체 길 수집이나 길찾기 완료를 뜻하지 않습니다.

줌 19 이상·기울기 75° 이상에서는 건물·도로·등고선·장소 핀을 **중심 ±300m의 전체 600m 정사각형**에서 조회합니다. 지면 화면 밖에 있는 가까운 고층 건물도 포함합니다. 근접 보기에서는 등고선·표고점과 라벨, 선택 연결선, 보간 음영·건물 테두리를 숨깁니다. 로컬 도로가 준비되면 중복 배경 도로·도로 이름도 숨기며, 일반 화면으로 돌아가면 기존 표시 설정을 적용합니다. 원본 좌표·높이·체크값은 유지합니다.

차도는 최대 12px, 보행로는 3px, 횡단선·계단은 3.5px의 연한 중심선 기호입니다. 도로의 실제 미터 폭을 나타내는 면이 아닙니다.

진입 시 중심에서 경위도 ±0.0015° 범위의 가까운 길을 먼저 조회합니다. 길을 찾지 못한 경우에만 기존 넓은 범위로 재시도하며, 같은 응답을 고정 모형에도 재사용합니다.

## 검증과 이전 기록

`tests/mobility.spec.ts`는 기존 파일명을 유지하되 정적 모형 E2E로 교체했습니다. 일반·최대 줌에서 경로 요청 없음, 1인칭 정착 후 프레임·좌표 불변, 미터 치수·지면 앵커, 3m 이동과 토글 후 좌표 보존, 종료·실패 처리를 검사합니다. 기존 카메라 확대·휠·드래그·복귀 회귀도 유지합니다. 이번 버전의 브라우저 실행 결과는 [VERIFICATION.md](../VERIFICATION.md)에 따로 기록합니다.

이전 20.5줌 자동 표시, 15fps, 24명/12대, 400m·50m 격자·3영역 캐시, 경사에 따른 땀·속도 변화는 **제거된 애니메이션의 과거 동작**입니다. 관련 성능 파일은 이전 측정의 보존 기록이며 현재 정적 모형의 성능 근거로 사용하지 않습니다. [성능 기록](PERFORMANCE.md).
