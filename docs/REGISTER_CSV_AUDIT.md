# 서울시 건축물대장 표제부 CSV 전수 감사

확인일: **2026-09-08**. 로그인과 API 키 없이 공식 Sheet 화면의 CSV 내려받기 폼으로 받은 파일이다. **585,194행 전체가 62열**이고, 같은 날 공식 샘플 API가 알려 준 `list_total_count=585194`와 정확히 일치한다. 공식 공개 데이터셋의 모든 행을 받은 근거이며, 서울에 실재하는 모든 건물의 완전성이나 높이 정확도를 보증하는 의미는 아니다.

**공식 CSV는 확보했지만 운영 지도에는 반영하지 않았다.** 이 파일에는 높이·대장 일련번호·주소·동명이 있고 건물 외곽선 및 경위도는 없다. 현재 Overture 도형 ID와 직접 대응하는 공통 식별자도 확인되지 않았다. 주소나 층수만으로 임의 매칭하지 않았다.

## 높이 등록 상태

아래 비율의 분모는 파일의 대장 행 전체이다. **양수는 숫자가 양수로 기재됐다는 뜻이며 품질 검증을 통과한 건물 수가 아니다.** 높이의 현장 측정 정확도, 건물 현황과의 일치, 이 CSV의 상세 측정 기준은 이번 감사로 확인하지 않았다.

| 음수 | 5 | 0.0009% |

- 양수의 최솟값은 `0.08`, 최댓값은 `13438`이다. 원문 숫자를 보존했으며 단위나 소수점을 임의 보정하지 않았다.
- 1,000 초과 값 6행, 500 초과 7행, 0보다 크고 1보다 작은 값 25행이 있다. 500을 넘는 값이 전부 오류라는 판정은 하지 않는다.
- 높이가 0인데 지상층수가 양수인 행은 247,365개, 높이가 빈 값인데 지상층수가 양수인 행은 2,827개이다. 0을 실제 건물 높이 0으로 표시하거나 층수로 임의 보충하면 안 된다.
- 양수라도 아래 극단값처럼 추가 확인이 필요한 행이 있으므로, `source_height_verified=false`를 유지한다.

## 문자 인코딩 오류

헤더가 CP949이지만 strict CP949 디코딩은 원본 중간에서 실패한다. 감사에서는 `errors="surrogateescape"`로 잘못된 바이트를 되돌릴 수 있는 상태로 보존했으며, `errors="replace"`나 `ignore`로 지우지 않았다.

- 데이터 행 **19,962**: `기타구조정보` 끝에 디코딩 불가 바이트 `0x82` 1개.
- 데이터 행 **205,979**: `기타용도내용` 끝에 디코딩 불가 바이트 `0x82` 1개.
- 합계 **2행·2바이트**이다. 높이·식별자 열에는 해당 오류가 없고, 두 행도 모두 62열이다. 원본 CSV는 수정하지 않았다.

이후 가져오기에서는 해당 원문 바이트를 보존하고 문제 상태를 표시해야 한다. 임의로 다른 인코딩 전체를 적용하거나 내용을 추측해 보정하지 않는다.

## 공개 다운로드 재현

공식 페이지의 Sheet 탭에서 **내려받기(CSV)**를 누르는 것과 같은 공개 폼이다. 실제 HTML의 기본값을 사용했으며 계정·토큰·쿠키를 주입하거나 인증 제한을 변경하지 않았다. `ssUserId=SAMPLE_VIEW`는 비로그인 페이지가 자체 제공한 공개 값이다.

```sh
curl --fail --location \
  --output seoul-building-register.csv \
  --data-urlencode 'srvType=S' \
  --data-urlencode 'infId=OA-22424' \
  --data-urlencode 'serviceKind=0' \
  --data-urlencode 'pageNo=1' \
  --data-urlencode 'gridTotalCnt=' \
  --data-urlencode 'ssUserId=SAMPLE_VIEW' \
  --data-urlencode 'strWhere=' \
  --data-urlencode 'strOrderby=' \
  --data-urlencode 'filterCol=필터선택' \
  --data-urlencode 'txtFilter=' \
  'https://datafile.seoul.go.kr/bigfile/iot/sheet/csv/download.do'
```

자료는 갱신될 수 있으므로 다시 받은 파일의 해시·행 수는 달라질 수 있다. 새 파일은 별도 시점으로 감사한다. Sheet 표시 상한 1,000행, 인증 없는 API `sample`의 1–5행 범위, 전체 CSV 다운로드는 서로 다른 제공 방식이다.

감사 코드는 이 컴퓨터의 `/tmp/seoul-building-research/audit_register.py`, 결과 JSON은 같은 디렉터리의 `register-audit.json`, 극단값 목록은 `register-outliers.json`에 보관했다. 임시 경로이므로 장기 보존 원본은 프로젝트의 `data/sources/` 파일을 사용한다.

```sh
.venv/bin/python /tmp/seoul-building-research/audit_register.py
```

감사는 CSV를 스트리밍으로 읽어 모든 행의 열 수, Decimal 기반 높이 분류, 구별·대장별 집계, 일련번호 중복, 디코딩 실패를 계산했다. 원본 CSV나 지도 DB를 변경하지 않는다.
