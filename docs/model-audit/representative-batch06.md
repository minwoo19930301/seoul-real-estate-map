# 대표 모델 batch06

사진을 참고한 거친 대표 외관 모델 3개 단지, 소스 폴리곤 30개. `completionCredit=false`. 개별 동 정밀 복원이나 실측 정확도를 주장하지 않는다.

| 단지 | 소스 폴리곤 | 높이 | 외관 근사 |
|---|---:|---|---|
| 등촌3단지주공 | 9 | 원본 15층 × 3m = 45m 추정 | 흰색·회색 판상형, 넓은 측벽, 반복 창열 |
| 래미안강동팰리스 | 3 | 원본 137/145/137m 유지 | 회백색 고층, 수직 창열, 단순화한 옥탑 |
| 온수힐스테이트 | 18 | 원본 31/33m 및 11–13층 유지 | 밝은 벽과 주황 수직 패널 |

원본 배치·방향·외곽선·높이를 유지했다. 공식 동수와 일치한다는 이유로 개별 동 대응을 확정하지 않았다. sourceIssues가 없고 선택 단지의 전체 소스 ID 집합이 일치함을 확인했다. 최신 origin/main과 현재 HEAD의 bespoke/reference/representative 소유권 중복은 없었다.

사진 4장과 승인 3개 단지의 양방향 고가 시점 렌더 6장을 직접 확인했다. 첫 렌더의 두꺼운 창살, 상단 잘림, 필로티처럼 보이던 기단을 수정한 뒤 다시 확인했다. 등촌의 실제 돌출 발코니·계단실 홈, 강동팰리스의 높은 수직 핀과 곡선 옥상, 온수의 적색 하부 패널·유리 엘리베이터는 재현하지 않았다. 온수의 연구 요약 6–12층과 소스 11–13층 차이를 기록하며 소스를 임의 수정하지 않았다. 지형·조경·포디움은 생략했고 보이지 않는 면은 대표 패턴이다.

세곡푸르지오는 입구에 외관이 가려 보류. 나머지 20곳은 기존 연구에 검증 가능한 로컬 사진이 없어 보류했다. 새 검색을 수행했다는 주장은 없다. 사진 자체는 배포하지 않고 출처 URL과 SHA-256만 보존한다.

실제 BlenderMCP PID 73533 / 9885에서 생성·검증했다. 편집 blend는 개별 소스 ID 메시를 유지한다. 배포 GLB는 단지당 재질 6개, 약 1.25–1.89MB. MCP 기록, 렌더, 독립 입력과 생성 코드를 보존했다.

검증: scene-validation의 30개 외곽선/높이 보존, validate_representative_models 통과, Node fallback 테스트 2개 및 Python publisher 테스트 2개 통과. 엄격한 bespoke 완료 통계는 변경하지 않았다.
