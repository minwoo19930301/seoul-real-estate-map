# 덕수궁 중명전 개별 재구성 근거

현재 `civic-4c53ad91-93b0-4472-b7a4-0086e45cbdd2`는 전용 형상을 찾지 못해 `district-public-office` 입면으로 생성된 자산이다. 신규 자산 `bespoke-jungmyeongjeon`은 이 한 건만 대체한다. 사진과 복원 도면을 보고 Blender MCP에서 개별 작성하며, 도시 전체 외관을 확인했다는 의미가 아니다.

## 형태와 방향

정면은 남향이며 약간 서쪽으로 기운 방향을 원본 윤곽에서 읽었다. 건물 가로축을 동쪽 기준 -2.4도로 회전해 정점을 굽고, 지도 기준점은 기존 자산의 `126.9725588920004, 37.56673044964224`를 유지한다. 복원 배치도의 북쪽 방향과도 대조한다. 동서 양면을 뒤집거나 긴 동측 회랑을 서측에 놓지 않는다.

정면 아치 7칸, 긴 동측 8칸, 짧은 서측 6칸은 모두 실제 빈 공간을 갖는다. 정면 중앙의 돌출 현관과 그 위 난간은 본체 회랑과 별도 부재다. 후면은 정면을 복제하지 않고 창 배열과 들어간 모서리, 막힌 아치와 열린 반환 회랑을 구분한다. 지붕 역시 직사각형 모임지붕 한 개가 아니라 꺾인 평면에 맞춘 마루·골·처마를 가진다. 굴뚝과 돌출 지붕창은 따로 작성한다.

회랑 깊이·마감·아치 곡률·조적 세부는 도면과 사진을 함께 읽은 재구성이다. 내부 전시와 감춰진 구조재는 생략한다. 사진을 텍스처로 넣지 않고 벽돌·회색 띠·석재 난간·목재·슬레이트를 실제 메시와 재질로 표현한다. 반복 벽돌 줄눈은 조적 표현이며 건물 입면을 자동 선택하는 템플릿이 아니다.

## 소유권과 남겨야 할 건물

소유하는 원본 ID는 `4c53ad91-93b0-4472-b7a4-0086e45cbdd2` 하나다. 원본에는 parent와 child parts가 없고 기존 Flight/bespoke 모델이 이 ID를 소유하지 않았다. 대체 ID도 위의 기존 civic 자산 한 개로 한정한다. 덕수궁 전체, 정동극장, 인접 대사관 건물, 옹벽과 정원은 포함하지 않는다.

기존 OVT 윤곽은 도면 치수보다 크다. 기존 앵커와 방향은 유지하되 건물 폭을 약 24m 윤곽에 맞추려고 실측 도면을 늘리지 않는다. 지도 배치 오차 가능성은 남으며, 새 모델이 정상적으로 그려지기 전까지 기존 자산이 fallback으로 남아야 한다.

## 재현과 검토 산출물

`scripts/bespoke/jungmyeongjeon.py`를 독립 Blender 포트 9876에서 실제 `execute_blender_code`로 실행한다. 동일 장면에서 `jungmyeongjeon_render.py`로 남서 정면, 남동 정면, 북서 후면, 지붕, 정면 입면을 렌더링한다. `jungmyeongjeon_validate.py`는 GLB 실제 bytes, 미터 bounds, 최소 높이 0, 유한 정점·단위 법선, 베이크된 변환, 단일 소유권과 외부 이미지 미포함을 확인한다.

ignored 작업 폴더는 `data/model-source/bespoke/jungmyeongjeon/`이며 `.blend`, `.glb`, 입력 recipe, source footprint, MCP 기록, 비교 렌더와 검증 JSON을 담는다. 원본 사진·보고서와 도면 검토용 이미지는 `data/model-source/bespoke/next-review/deoksugung-research/`에만 보관한다. 원본 이미지의 복제·배포 권한을 모델 제작 권한으로 간주하지 않는다. 공개 모델 게시와 최종 시각 검토는 별도 단계다.
