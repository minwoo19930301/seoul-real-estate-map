# 강동 롯데캐슬 퍼스트 모델링 재개

2026-10-02. Blender 4.5.11을 GUI 없는 background 프로세스로 실행하고, 실제 upstream Blender MCP stdio → localhost addon → main-thread queue 경로로 제작했다. Safe mode와 외부 네트워크 차단을 유지했다. 사용자 창 활성화나 화면 전환을 사용하지 않았다.

110동 한 개를 사진과 대조해 제작하고 35동은 같은 GLB의 메시·재질을 공유한다. 30층·83.4m 대표 모델은 30,152 triangles다. 첫 버전의 균일 창문 격자를 반려하고, 두 창 묶음·중앙 벽·발코니 난간·금색 포인트·석재 기단·개방 옥상 프레임을 수정한 V2를 검토했다.

식별된 36/40동만 반영했다. 동별 위치·방향·전체 크기를 변환했으며 창문과 층 패턴은 대표 동을 반복하므로 개별 실물 재현이 아니다. 후면·방향·세부 치수는 추정이다. 원본 사진은 저장소에 포함하지 않는다.

기존 generic GLB의 24,578 triangles를 원본 생성 코드로 byte-exact 재현해 36개 fallback으로 분리했다. 이전 GLB와 64개 correction 기록은 보존한다. 새 모델 실패 시 단독 fallback, 그것도 실패 시 기존 지도 건물이 복원되는 브라우저 검사 3개가 통과했다.

대표 4뷰와 GLB/BLEND 재로드 검증, 공유 배치 충돌 검사, Node 자산 검사, Python 공유 배치 검사, 프로덕션 빌드 통과. 지도 화면에서도 모델 공유와 원본 건물 중복 숨김을 확인했다. PR 반영은 배포를 의미하지 않는다.
