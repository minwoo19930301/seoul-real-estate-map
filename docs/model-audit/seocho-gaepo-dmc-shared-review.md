# 서초·개포 대표 공유와 DMC 확장

2026-09-22. 네 단지의 대표 한 동씩을 제작하고 나머지는 같은 GLB와 재질을 공유했다. DMC는 기존 301 대표를 그대로 재사용했다. 대표 4개와 복제 107개로 111동을 추가했다. 복제별 사진 조사나 모델·렌더 제작은 하지 않았다.

서초의 넓은 짙은 끝벽과 밝은 모서리, 포레스트의 밝은 창 격자·청색 유리와 열린 긴 옥상 프레임, 블레스티지의 큰 청록 창면과 두꺼운 옥상 보, 아너힐즈의 넓은 아이보리 벽·짙은 저층부를 사진과 대표 네 방향 렌더로 대조했다. 서초 사진의 109 번호는 확인됐다. 다른 세 대표의 번호와 사진 방위는 미확정이며 단지 외관을 적용한 추론이다. 블레스티지 사진에 보이는 이웃 201을 대표 209로 오인하지 않았다.

## 배치와 보존

주소·지번·동번호·층수·높이 대조와 실제 SQLite 원천을 독립 확인했다. 복합 모델의 소유 ID는 단지 경계의 증거가 아니므로, DMC는 서로 다른 기존 generic 그룹에 속해 있어도 정확한 가재울미래로 2 / 남가좌동 385 조건을 통과한 33개 원천을 추가했다. 기존 여섯 동의 기록은 보존했다. 나머지 주소와 미확정 원천은 그대로 남는다.

대표의 평면·창문·층 패턴을 반복하고 위치·방향·크기를 바꾼다. 아너힐즈 322·323의 복제 본체 겹침을 발견해 가로 변환을 92%로 조정했다. 좌표·높이·모델 파일은 그대로이며 두 본체 사이 거리는 약 0.56m다. 각 동의 실제 오목한 평면과 입면을 따로 재구성한 것은 아니다.

기존 복합 모델 여덟 개의 79,487개 삼각형을 원본 제작 순서로 재현해 바이트 일치를 확인한 뒤 분리했다. 주변·미확정 원천 42개와 지형 앵커·재질·정점 속성을 보존했다. 단일 원천 fallback 24개도 기존 파일을 그대로 사용한다.

## 검증

- Node 13,869개, Python 57개, 브라우저 15개 시나리오와 프로덕션 빌드 통과. 아너힐즈 배치 수정 후 해당 브라우저 세 시나리오도 다시 통과했다.

- 현재 공유 복제 397동의 본체와 같은 단지의 식별된 원천 사이 겹침 0건. DMC처럼 추가 게시된 동일 단지도 관리코드로 합쳐 배치를 검사하도록 수정했다. 전체 주변 건물·장식 돌출 검사는 아니다.
