## 배치와 보존

힐스테이트 123동은 두 부분으로 나뉜 MultiPolygon이다. 배치기와 검사기가 모든 부분과 구멍을 보존해 처리하도록 수정했다. 두 번째 부분과 이웃, 중정 구멍을 빠뜨리지 않는 회귀 검사를 추가했다.

새로 확인된 아르테온 327동 원천과 기존 326동 복제 본체가 약 0.081㎡ 겹쳤다. 이전 326동 기록과 GLB를 보존한 채 새 ID의 배치 수정본을 추가했다. 수평 변환만 약 1.2216% 줄여 최소 0.2001m 간격을 확보했다. 좌표와 높이 95.25m는 유지한다. 기존·신규 모든 공유 복제 521동의 검사 범위 내 본체 겹침은 없다.

두 분리 묶음은 기존 삼각형 100,311개와 주변 108개 원천을 보존한다. 이미 분리한 residual도 원본 재생과 현재 바이트 일치를 먼저 확인하고 새 파일로 분리했다. 기준 e9671a393의 기존 bespoke 910개·reference 125개·generic 13,607개 기록, correction 52개, GLB·blend 114,770개 파일 바이트가 유지됐다.
