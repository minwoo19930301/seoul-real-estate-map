[W04/W05 방문 사진](https://first.useful2know.com/m/entry/%EB%A9%94%EC%9D%B4%ED%94%8C-%EC%9E%90%EC%9D%B4-%EC%9E%84%EC%9E%A5%EA%B8%B0-202503)은 동선상214 다음215이며, 캡션과 큰 L 내부 코어 형태가 P/A와 일치합니다. 화면 오른쪽 뒤의 별도213은 모델에 포함하지 않았습니다. 사진 안에서214 숫자를 직접 읽지는 못했으므로 번호 확정 근거는 배치·동선·L 형태·옥탑 교차 대응입니다.
