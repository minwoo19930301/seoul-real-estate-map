# 트리지움·은마 대표 모델 공유 적용

2026-09-22. 트리지움344동과 은마21동을 각각 한 번 제작·사진 검토한 뒤, 형제동71개는 해당 GLB의 메시·재질을 공유했다. 복제별 Blender 제작이나 사진·4방향 렌더를 반복하지 않았다.

트리지움은 등록 높이·층수를 사용한다. 은마는 대장 높이가0이며 원천 지도 높이도 비어 있다. 14층에 층당3.05m를 적용한42.7m는 명시적인 추정값이다. 사진에서 은마 전경 건물의 번호는 확정하지 못했으므로 단지 공통 외관을21동에 적용한 추론으로 기록했다.

공유 복제는 대표의 창문·층 패턴·지붕·평면 형태를 그대로 반복한다. 원천 위치·방향·전체 크기에 맞춰 변환했으며, 각 동의 실제 오목한 평면이나 층별 입면 차이를 재현하지 않는다. 대표 번호는 복제에서 숨긴다.

## 기존 건물 보존과 배치

트리지움305동은 이전 리센츠 작업에서 남긴 복합 fallback에 섞여 있었다. 기존 교정 결과를 새로운 ID로 다시 분리하는 `repartition`을 추가했다. 이전 파일과 교정 기록은 그대로 두고, 현재 유효한 소유권·해시·전체 원천 분할을 검증한 뒤 새 분할을 적용한다. 트리지움 주변37개, 은마 주변5개 원천 건물을 유지했다.

파크리오201/203과202/204 복제 본체 간 겹침은 새 배치 자산으로 수정했다. 네 동의 높이·앵커는 유지하고 수평 크기만 줄였으며, 본체 평면 간 최소 간격은0.643m다. 네 단지의 현행 공유복제163개를 검사해 복제 본체끼리 또는 이웃 원천 본체와 겹치지 않음을 확인했다. 장식 돌출과 실측 일치는 이 검사 범위에 포함하지 않는다.
