# 메이플자이 실제 GLB 외관 감사 / 2026-09-20

**판정: 동별 배치·윤곽 자료는 보존하고, 입면·옥탑·공용 연결부는 개별 재작업한다. 기존29동 전체를 실물 검토 완료로 간주하지 않는다.** 현재 모델은 완전히 같은 타워의29복사본은 아니다. 그러나 서로 다른 외곽에 반복 창호·크라운 규칙을 적용한 결과여서, 별도파일·해시·수동trace만으로 동별 실물 재현이라고 보기 어렵다. 기존 `major-apartment-reference.md`의 메이플자이 일괄 유지 판단을 이 감사로 한정한다.

## 실제 확인 방법

Blender4.5.11 MCP9878에서 `public/models/maple-xi/`의31GLB를 직접 가져와 메타데이터 좌표대로 배치했다. 생성 코드를 실행하거나 공개 모델을 변경하지 않았다. 101동·104동을 각각 렌더하고210/211동을 함께 양쪽에서 렌더했다. 전체 단지 남서/북동 사시도와 번호가 보이는 평면도도 만들었다.31개 public SHA가 저장된 모델recipe와 일치함을 확인했지만, 이는 **검토 대상 파일 식별**에만 사용한다.

## 210/211 별도 Blender 재제작 / root 검토 전

`data/model-source/bespoke/maple-club-cloud/`에 새 `bespoke-maple-xi-210.glb`, `bespoke-maple-xi-211.glb`, 편집 가능한 `maple-club-cloud.blend`와 `bundle.json`을 만들었다. 기존31GLB는 수정하지 않았다. 기존210앵커는 연결교를 포함한 bounding-box 중심이므로 이를 그대로 사용하고, 각 외곽은 기존 경위도 footprint에서 해당 앵커로 다시 투영했다. 새 모델을 중심으로 다시 recenter하지 않았다.

새 입력 `authored-input.json`에는 두 동의 각 면에 대한 별도 구획과 창폭/회색면/슬릿창 결정을 기록했다.101/104 등 다른동을 생성하는 반복동목록이나 공통 facade분류를 사용하지 않는다. 반복되는층 자체는 실제 공동주택의 반복층을 표현한다. 두동의 평면은 보존하면서 입면의 구역폭과 창 조합을 각각 지정했다.

실물 비교에서 수정한 부분은 다음과 같다.

- 옥상은 210동의 한 복합 설비실과 낮은 부속 볼륨, 211동의 폭·높이·방향이 다른 두 긴 설비실로 나눴다. 상부 캡과 환기구·루버도 분리했다. 실제 사진에 보이는 설비실의 역할/정확한 치수는 추정으로 남긴다.
- 단순한 직각 유리띠 대신 라운지의 둥근 코너 리턴, 연속 돌출 캐노피, 하부 음영띠, 수직·수평 멀리언, 옥상 난간을 분리했다. 코너 곡률은 준공 실사진의 시각적 비율에 따른 해석이며 CAD값이 아니다.
-210동 긴 입면의 밝은 면·회색 면·좁은 창과 넓은 창을 구획별로 달리하고,211동은 L형 안쪽 입면과 고속도로측 밝은 벽·회색 창호 구획을 별도로 구성했다. 보이지 않는 면과 정확한 bay 수는 확정하지 못했으므로 survey-faithful로 표시하지 않는다.
- 연결교의 하부 박스, 유리 통로, 캐노피와 수평 트랜섬을 독립 메시로 구성하고 양끝 라운지에 접속시켰다. 소유권은210동에만 둬 중복되지 않게 했다.

비교용 원본 GLB 렌더와 새 `courtyard.png`, `highway.png`, `roof_close.png`, `under_bridge.png`, 실제 MCP viewport를 root가 다시 검토해야 한다. 라운지29층이라는 근거는 유지하되 총높이90.16m, 개별 창폭·층고·옥탑 높이·코너 반경은 사진 기반 추정이다. **두 동의 이번 개선을 나머지27동의 검토 완료로 확장하지 않는다.** 101/104는 부분감사를 했지만 정밀 입면검증과 재작업은 아직 대기다.
