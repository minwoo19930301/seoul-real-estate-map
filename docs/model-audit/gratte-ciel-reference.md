# 청량리역 한양수자인 그라시엘

## 식별과 범위

관리코드 `A10023188`, 동대문구 용두동의 1,152세대 단지다. [수자인 공식 개요](https://m.sujain.co.kr/complex/crrgratteciel/overview)와 [공식 배치도·동호수표](https://m.sujain.co.kr/complex/crrgratteciel/plan)를 대조했다. 101동 59층·321세대, 102동 55층·303세대, 103동 50층·271세대, 104동 56층·257세대로 합계가 일치한다. 101/102/103은 여섯 세대 방향을 가진 굴곡 평면, 104는 다섯 세대 방향의 다른 평면이다.

주거타워 네 동을 각각 만든다. 상가 기단은 단순화하며, 단지 전체 상가·옥상 정원·실내·지하주차장을 완성한 모델이라는 뜻은 아니다. 주변 해링턴플레이스와 롯데캐슬 동은 포함하지 않는다.

[서울시 건축물대장 표제부](https://data.seoul.go.kr/dataList/OA-22424/S/1/datasetView.do)의 2026-09-08 스냅샷에서 용두동 798, 고산자로32길 78, 101–104동이 정확히 일치하는 네 행을 확인했다. 동별 층수와 세대수도 수자인 표와 일치한다. 원문 행과 SHA-256은 `official-register-source.json`에 보존한다. 대장 높이를 보수적인 전체 외곽 높이로 사용했으며, 대장값의 옥탑 장식 포함 범위는 미확인이다. 7.2m 옥상 프레임을 그 외곽 안에 배치한 해석은 사진 비례 추정이지 최상단 실측값이 아니다. 단지명에 과거 들어간 `192`를 모든 동의 높이로 적용하지 않는다. 지도 외곽선의 전역 위치와 동 번호는 북향 표시가 있는 공식 배치도로 대조했다. 각 GLB는 자기 건물 중심에 고정하고, Blender 검토 장면에서만 `siteEN` 이동을 적용한다.

## 실사진에 따른 형상

- [BS한양 2023년 6월 입주 기사](https://www.archiveh.co.kr/board/board.php?bo_table=sujain&idx=17)의 완공 전체 사진과 외벽 확대 사진: 짙은 갈색 바탕, 넓은 단일 창 세로 띠 사이의 흰 창틀 묶음, 아래층의 붉은색·황토색 돌출 발코니를 구분했다.
- [BS한양 우수디자인 기사](https://www.archiveh.co.kr/board/board.php?bo_table=sujain&idx=20)의 완공 사진: 위브드 패턴의 서로 다른 돌출 깊이, 옥상에서 열린 채 연장되는 흰 입체 프레임, 상가의 적갈색과 유리 기단을 대조했다.
- 공식 동호수표의 29층은 피난층이다. 첫 렌더에 있던 건물 전체를 두르는 검은 띠는 완공 사진과 달라 제거했다. 주 입면의 흰 창틀은 이어지고, 서비스 부분에서만 작은 통풍구로 나타낸다.
- 첫 렌더의 균일한 격자도 반려했다. 긴 면을 여러 흰 창틀 영역과 짙은 서비스 띠로 직접 나누고 창 폭을 달리했다. 평평한 옥상 스크린은 뒤쪽 프레임과 연결 가로재를 갖춘 열린 구조로 바꿨다.

외곽선과 사진에서 확인한 동별 요소만 이 단지용 `authored-input.json`에 둔다. 네 동의 실제 공통 건축 언어를 표현하는 함수는 다른 단지에 적용하는 생성 템플릿이 아니다. 창 크기·부재 두께·가려진 후면·옥상 설비는 사진 비례 추정이고, 보이지 않는 면까지 정확하다고 승인하지 않는다.

## 재현과 검토

`scripts/bespoke/gratte_ciel.py`를 실제 Blender MCP로 실행하고, 별도 호출에서 `gratte_ciel_render.py`로 남서·북동·평면·옥상 네 방향을 렌더한다. 최종 시각 검토 여부와 원본 해시는 `published-bespoke.json`의 해당 사이트 기록으로 판단한다. 이 문서나 생성 스크립트가 존재하는 것만으로 게시 또는 검토 완료로 간주하지 않는다. 원본 사진은 외부 링크로만 기록하고 저장소에는 새로 만든 모델과 렌더만 넣는다.
