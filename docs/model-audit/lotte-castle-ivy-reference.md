## 확정치와 추정치

대장102017214는 동명 공란의 단지 단일 행:112.25m /35F/B6 /445세대입니다. **112.25m를 동별 측정 최상단 높이라고 주장하지 않습니다.** 두동 본체 상단에 공유 기준으로 적용하고, 날개 단차와 경사 유리, 추가 작은 크라운5.0–5.3m는 사진 추정입니다. 최종 mesh 높이는 크라운/프레임까지 약117.4–117.7m이나 이는 측량값이 아닙니다.

101NW·102SE 외측 끝면의 평유리와 단차는 실제 사진에 맞춰 유지했습니다. V면을 중앙 연결체를 향한 내측 끝으로 두는 것은 여러 시점을 조합한 **잠정적인 입면 배정**입니다. 준공 입면도, 정확한 파노라마/사진 GPS가 없어 확정 면 매칭으로 승격하지 않았습니다. 반대면의 미세 창열, 작은 설비, 현재 모든 상가 변경은 확인하지 못했습니다.

v3의 외벽 끝까지 붙은 큰 경사 유리 덮개를 제거했습니다. v9은 수직 창벽을 각 날개 상단까지 유지하고, 삼각 경사 유리를 끝면 쪽에서 약0.85m 물려 분리합니다. 이 후퇴량 역시 사진 추정입니다. 최상부 작은 경사 지붕은 낮은 전면 카메라에서도 부분적으로 보이도록 실제 외측 주탑 방향으로 배치했습니다.

## 재현

`.blend`는 실시간 Blender MCP9877에서 만든 편집 가능한 mesh 원본입니다. `prepare.py`는 함께 보존한 source-footprints.json으로 recipe를 만듭니다(Shapely 필요). `build.py`는 같은 디렉터리의 recipe.json만으로 Blender에서 재생성할 수 있습니다. 독립된 빈 Blender에서만 실행하세요. 카메라 비교용 `photo_camera.py`,6뷰 `render.py`, 검증 `finalize.py`는 staging 경로를 자기 파일 기준으로 해석합니다. 원본 building DB/레지스트리를 다시 긁지 않아도 현재 보존한 authored recipe로 geometry를 재현할 수 있습니다.

MCP 실행 기록은 mcp-build-v9.json이고 GLB/blend/hash 검증은 geometry-validation.json으로 기록합니다. root가2026-09-21 v9 실제사진 대조를 승인했습니다. 가려진 평지붕, 내측V 방향/치수, 기단 세부는 계속 미확인입니다. 실제 배포 확인은 release verification 기록으로 따로 남깁니다.
