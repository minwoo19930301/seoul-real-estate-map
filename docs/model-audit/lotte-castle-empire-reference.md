# 여의도 롯데캐슬엠파이어

A15088614, 406세대의 101동·102동을 실제 Blender MCP로 개별 재구성했다. 공동 연결체와 저층 상가는 별도 모델이며 주거동 수에 포함하지 않는다.

미쓰비시전기의 [실제 건물 사진](https://www.newswire.co.kr/newsRead.php?no=1042912)은 기단의 `LOTTE CASTLE EMPIRE` 표기로 식별했다. [시공 담당자의 2004년 논문](https://www.auric.or.kr/pdf_view/pdf_view2_open.asp?filename=ex_KCI_1_2004_11_77(C).pdf)은 39층 두 동과 406세대를 명시한다. 101동은 북서쪽, 102동은 남동쪽으로, 번호가 기재된 감정평가 항공사진과 여러 방향의 실제 거리 사진을 대조했다. 공식 관리사무소 배치도에는 이미지가 없어 번호 증거로 쓰지 않았다.

두 동의 계단식 유리 옥탑은 같은 남동쪽으로 높아진다. 초기 101동의 반대 방향 옥탑은 수정했다. 계단 사이 경사진 유리면과 삼각 측면, 은색·아이보리 프레임, 녹청색 유리, 세로 환기 띠와 실제 후퇴한 개구부를 구분했다. Blender 광선 검사에서 홈 안쪽 벽은 외벽보다 1.01m 뒤에, 층판은 0.06m 앞에 있다.

공동 대장 126m는 동별로 독립 측정된 값이 아니다. 모델은 이를 가장 높은 유리 지붕의 기준으로 삼았으며 프레임 최상부는 126.169m다. 계단 높이, 유리 경사면의 깊이, 가려진 뒷면 창 배치와 정확한 색은 사진을 근거로 한 추정이다. 실측 CAD나 전면 360도 검증을 주장하지 않는다.

기존 `apt-a15088614`에는 이웃 미성 A동이 잘못 포함되어 있었다. 원본 GLB를 보존한 채 모든 삼각형·재질·정점 속성을 그대로 분리했다. 엠파이어 1,967개와 미성 A동 551개를 합하면 원본 2,518개다. 새 모델은 수정된 엠파이어 부분만 대체하며 미성 A동은 정상 로딩과 의도적인 HTTP404 모두에서 남는다.

편집 가능한 `.blend`, 재현 소스, 여섯 비교 렌더, 실제 MCP 실행과 홈 검사 기록의 해시는 `published-bespoke.json`에 연결되어 있다. 외부 원본 사진은 모델에 삽입하거나 저장소에 배포하지 않는다.
