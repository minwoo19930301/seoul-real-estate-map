센트럴아이파크는 HDC의 실제 단지 사진에 보이는 밝은 벽, 쌍창, 차콜 서비스 벽, 작은 노란 돌출판과 석재 저층부를 반영했다. 사진 오른쪽 배경의 번호는 513이며, 512동의 직접 사진 증거는 아니다. 옥상은 가려져 보수적으로 단순화했다.

래미안힐스테이트는 밝은 벽과 청록빛 수평 창, 회색 서비스 면을 반영했다. 사진의 101은 앞쪽 출입부에서 읽히며 126동 번호 증거는 아니다. 최초 옥상 프레임은 사진보다 가늘어 수정했다. 두꺼운 기둥과 연속된 상부 캡 아래를 열린 공간으로 두었고, 기존 본체는 유지했다. 부재 치수와 숨은 면은 추정이다.

복제는 대표의 평면과 창문·층 패턴을 반복하며 위치·방향·등록 높이에 맞춰 변환한다. 각 동의 실제 오목한 평면이나 층별 차이는 재현하지 않는다. 원천 OSM 높이와 등록 높이의 차이도 기록에 남겼다.

## 기존 모델과 런타임

기존 두 복합 모델의 32,489개 삼각형을 원본 제작 순서로 재실행해 바이트가 일치함을 확인한 뒤 원천별로 분리했다. 46개 대상 외 주변·미확정 건물 네 개와 지형 앵커, 재질, 모든 정점 속성을 보존했다. 과거 단순화로 생긴 볼록껍질 근사도 그대로 보존한다.

공유 복제 게시기가 이전 분할에서 삭제된 복합 모델 ID를 유효한 fallback으로 볼 수 있던 문제도 수정했다. 교정을 순서대로 적용해 최종 활성 소유권을 계산하고, 이미 사라진 ID를 가리키면 파일을 쓰기 전에 중단한다. 같은 ID로 남은 잔여 모델과 후속 완전 분할을 구분하는 회귀 검사를 추가했다.
