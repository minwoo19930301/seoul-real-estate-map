# 래미안 첼리투스 101·102·103동

이 단지는 삼성 래미안의 [공식 단지 개요](https://www.raemian.co.kr/sales/ichon)에서 **460세대·3개동·최고56층·2015년8월 입주**로 확인했다. 로컬 공동주택 원본의 `A10027908`도460세대다. 세 동을 개별 Blender mesh/GLB로 작성하며, 103동에 연결되는 두 스카이브리지와 단지 서쪽 저층 커뮤니티·캐노피를 같은 편집 장면에 포함한다. 대지 전체와 인접 건물을 소유하는 모델은 아니다.

101입면은9m 필로티+175m+12m 옥탑,102는9+129.7+8.4m,103은9+111.7+8.4m로 읽힌다. [삼성 C&T2017기술 기사](https://news.samsungcnt.com/en/features/engineering-construction/2017-05-bridging-the-sky-samsung-ct-pioneering-the-future-of-the-skybridge/)의201/166/150m와 다른 수치다. 이를 동일한 기준의 실측치로 합치거나 평균하지 않고, 모델은 치수가 명시된 건축 입면을 우선한다. source height196/147.3/129.3m도 두 작은 동에서0.2m 차이가 남는다.

공통 평면 계열은 각 동의 배치도·입면 key plan으로 확인했다. 101의 상세 평면을 근거로 창면 꺾임을 작성하되 **각 동의 층수·후면 두 날개 높이·17층 돌출부·다리 접합 위치를 따로 입력**한다. 작은 날개 지붕 높이·창틀 두께·색상·루버 간격은 도면과 사진의 비례 해석이다. 크라운의 전체 높이는101의12m와102/103의8.4m로 구분한다. 내부 설비 배치는101도면을 단순화한 것이며102/103별 상세 옥탑 배치는 확인되지 않았다. H와 원형 헬리패드 표시는 도면이 있는101에만 넣는다. 일반 창호는 실제 반복되는 커튼월 모듈만 공유한다.

## 남는 한계와 작업 상태

최종 모델의 독립 시각 승인과 해시는 `published-bespoke.json`에 기록한다. 이 문서만으로 공개 배포 완료를 판단하지 않는다. 준공2015사진과 건축문화대상 도면을 사용했으며2026실측 모델은 아니다.103의 가려진 지상 출입부, 후면 작은 설비구, 저층 커뮤니티의 일부 서비스 면은 사진이 부족하여 추정임을 남긴다. 건물 전체 내부, 지하 주차장, 정원·놀이터·식재 전부를 재현했다고 주장하지 않는다. 렌더 바닥과 조명은 검토용이며 내보내지 않는다.

재구성은 `authored-input.json`을 stage에 복구하고 `raemian_caelitus_blender.py`를 전용 Blender MCP에서 실행한다. stage 입력이 없으면 `modeling/bespoke/raemian-caelitus/authored-input.json`을 사용한다. `raemian_caelitus_prepare.py`는 로컬 source DB와 ignored reference ledger를 필요로 하므로 새 체크아웃의 무조건 실행 명령이 아니다. 개별 export는 입력의 각 `siteEN`만 역이동하고, 저장 `.blend`에서는 세 동의 원래 상대 위치를 유지한다.

## 준공사진 대조 후 v4 보완

남측 주요 창면의 네 축은 가는 커튼월 창살과 구분되는 폭0.78m·깊이0.62m의 돌 마감으로 작성했다. 위치는101평면35의 x505/653/1062/1190 축과 창면 꺾임에 맞춘다. 이 폭과 깊이는 준공사진 비례값이며 실측치가 아니다. 후면 y572 면에는 `aurum-03`에 보이는 얕은 패널 줄눈·중앙 세로 유리 슬롯을 추가했고,103의 북동측17층은 사진의 흰 프레임과 위아래 짙은 수평 루버를 구분했다. 작은 설비구 횟수는 추정이다.

필로티는101평면36의 직사각·벽기둥을 추적했다.102/103의 기단은 같은 평면 계열 및102서측 실제 사진으로 대조했지만 가려진 기둥마다 독립 실측 자료가 있는 것은 아니다. 캐노피 앞의 원기둥과 타워의 넓은 돌기둥은 별도 구성이다. 서쪽 커뮤니티는 `aurum-09`의 깊은 금속 fascia·목재 soffit, `aurum-08`/26의 직선 산책로·작은 pergola·외부 계단을 반영했다. 두 캐노피 타원은 실제 관통 구멍이다. 정원식재·모든 가구·별도 작은 rooflight까지 완성했다고 주장하지 않는다.

## 최종 후보와 실제 MCP 검증

Blender4.5.11 LTS의 전용9878 세션에서198개 이름 있는 구성요소, 총272,880삼각형을 작성·검증했다. 각 동 GLB는 같은 대지 좌표계에서 원래 source anchor만 역이동했고, 세 동 편집본은 상대 위치를 보존한다. 좌표·법선·텍스처 부재·최저Y0를 GLB 정규화로 점검했고, 실제 Blender mesh의 양의 부피·세 동 상단 높이·캐노피 두 타원의 하향 ray 관통도 확인했다.

실제 실행 증거는 `docs/model-audit/mcp/raemian-caelitus/{build,validation,render}.json`이며 bundle이 각 SHA256을 가리킨다. 검토 렌더6개와 실제 MCP viewport는 `modeling/bespoke/raemian-caelitus/review-renders/`에 복사했다. 원본 참조사진은 ignored stage에만 남았다. 저장 편집본 SHA256은 `06fd2a803c0844ceb62ab9edb44b9dae9f953d5848ac16e874ba4582e972a4d6`이며, GLB·입력·렌더별 frozen hash는 같은 modeling 폴더의 `frozen-inputs.json`에 있다. 이 freeze는 후보 파일의 식별이며 독립 시각 승인이나 배포를 대신하지 않는다.
