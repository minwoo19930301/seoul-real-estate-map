# 서울숲 트리마제 — 101–104동 개별 외관 재제작

검토일 2026-09-21. 기존 `apt-a10026988`의 공통 창문 띠 모형을 대체하기 위한 네 주거동이다. 실제 Blender 4.5.11 GUI의 전용 MCP 포트 9877에서 제작했다. 이 문서는 서울 전체나 단지 부속시설 전체의 완성을 주장하지 않는다. 최종 출판은 별도 통합 검토를 거친다.

## 형태·면별 선택과 수정

`authored-input.json`의 각 동 `parts`가 원본 외곽선의 어느 꼭짓점 구간을 어떤 높이의 날개로 해석했는지 기록한다. 외곽선은 주거동별 실제 OSM 도형이다. 내부 날개 경계는 사진을 보고 작성했으며 공식 CAD나 동별 상세 평면도라고 주장하지 않는다.

- 101동: 남서쪽 낮은 곡면 날개, 남동쪽 높은 수평띠 날개, 높은 직선 코어와 북동측 반대면을 분리했다. 낮은 날개 위로 보이는 높은 날개 연결면을 흰 석재로 잘못 분류했던 첫 시안을 수정하여 유리 수평띠가 위까지 이어지게 했다.
- 102동: 101과 다른 방향의 원본 평면을 사용한다. 동측 항공 사진에서 확인한 넓은 석재 코어 벽을 지정하고, 남동쪽 유리 날개 높이를 약99m의 사진 비례로 낮췄다. 북서·남서 수평띠 날개 높이는 별도로 작성했다.
- 103/104동: 좁은 고층 석재 날개와 넓은 평면 커튼월, 낮은 각진 가지를 각각 분리했다. 전체를 곡면 타워로 복제하지 않았다. 최고층수와 동별 높이, 유리 날개 높이가 서로 다르다.
- 평면 유리 입면의 밝은 불투명 패널은 사진의 분산된 패치를 단순화한 명시적 반복 도안이다. 창문 위치를 모두 실측했다는 의미가 아니며 난수로 채우지 않았다. 곡면 날개에는 굵은 흰 띠와 창 끝의 둥근 모서리를, 석재 코어에는 작은 세로창을 적용했다.
- 개방 기계층은 첫 시안의3.2m를 약2m로 줄이고 기둥 간격을 약3m로 좁혔다. 사진 비례를 개선한 수치이지 상세 구조도상의 치수는 아니다.
- 1층은 유리 로비·작은 캐노피·필로티로 표현했다. 수목에 가려진 면과 실내, 장비 상세는 확인되지 않아 단순화했다.

## 재현과 검증

`trimage_prepare.py`는 보존된 `source-footprints.json`과 `official-register-source.json`에서 제작 레시피를 만든다. 이 둘을 `modeling/bespoke/trimage/`에 보존하면 ignored 원본 DB 없이 레시피를 다시 작성할 수 있다. `trimage_blender.py`를 전용 실제 MCP의 `execute --port 9877 --script ...`로 실행한다. 재실행은 해당 전용 씬을 비우므로 사용자 Blender 인스턴스에서 실행하지 않는다. 기존 `.blend`를 직접 여는 편집 경로도 가능하다.

`trimage_render.py`는 실제 Blender에서 한강 쪽, 반대쪽, 동측, 지붕 배치와 101/103 개별 비교 렌더를 만든다. 사진과 카메라 위치가 정확히 일치한다고 주장하지 않는다. `trimage_finalize.py`는 per-anchor GLB 변환 적용, 유한 좌표·단위 노멀, 최저점0, 개별 대장 높이, 네 개 외곽선의 독립 소유, 이미지 미포함과 실제 MCP 실행 기록을 검사한다. 최종 해시는 staging의 `geometry-validation.json`과 `bundle.json`이 기준이다.
