# 아파트 대표형 모델 1차

단지별 사진 또는 조감도에서 고른 외벽·창·발코니·옥상 특징을 원본 외곽선에 반복 적용했다. 동별 정밀 실측 재현이 아닌 비용을 줄인 대표형 모델이다.

| 단지 | 원본 건물 폴리곤 수 |
|---|---:|
| DMC아트포레자이아파트 | 8 |
| 힐스테이트 홍은포레스트 아파트 | 8 |
| 강남센트럴아이파크 | 5 |
| 신반포자이아파트 | 7 |
| 서울숲리버뷰자이아파트 | 7 |
| 래미안개포루체하임 | 12 |

6개 GLB로 47개 원본 폴리곤을 표현한다. 각 GLB는 6개 재질 메시이며 총13.23MB다. 기존 위치와 높이를 유지했다. DMC아트포레자이는 원본 높이가 없어 기록된 층수×3m 추정이며, 홍은포레스트는 준공 사진 대신 공식 조감도 참고다. 후면, 창 간격, 일부 옥상 설비는 추정이다. 같은 수의 공식 동 수와 폴리곤이 있다고 해서 개별 동 이름이나 부속동 용도까지 확정한 것은 아니다.

더샵둔촌포레는 원본 슬래브 배치와 현재 모습의 대응을 확인하지 못해 런타임에 추가하지 않았다. 고덕과 서초의 오인 가능성이 있는 후보도 제외했다.

`representative-manifest.json`은 별도 목록이다. 기존 정밀 모델의 ID·footprint 소유권을 차지할 수 없고, 정밀 모델 완료 통계에 포함하지 않는다. 새 GLB가 실제로 그려진 뒤에만 같은 원본 폴리곤의 일반 모델을 숨기며, 로딩 실패 시 기존 건물을 유지한다.

실제 Blender MCP 실행 기록, 단지별 두 방향 렌더, 입력 해시와 불확실성을 보관했다. GLB 위치·크기·해시·재질 메시 수 검증, 런타임 교체/복구 테스트26개, Python 출판 검증7개, TypeScript/Vite 빌드를 통과했다. 로컬 지도 확인 기록은 `representative-browser-check.json`에 있다. 배포 완료를 의미하지 않는다.

편집용 씬과 재생성 입력은 `modeling/representative/representative-batch01/`에 있다. 기준 사진은 출처 URL과 해시만 기록하고 저장소에 재배포하지 않는다.
