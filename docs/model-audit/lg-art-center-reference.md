# LG아트센터 서울·LG디스커버리랩 개별 복원 근거

이번 대상은 기존 `landmark-2623bbf0-348f-4cec-94c6-dc8ca4977552` 한 개다. 같은 원본 윤곽 안에 있는 공연장과 디스커버리랩을 함께 다루며, 주변 LG사이언스파크·서울식물원·지하철역은 소유하거나 대체하지 않는다. 기존 모델은 높이 정보가 없는 윤곽에 약9.56m 일괄 높이를 준 모델이다. 원본은 보존하고 별도 `bespoke-lg-art-center-seoul-discovery-lab`로 제작한다.

## 직접 확인한 주요 근거

- [간삼건축 프로젝트](https://www.gansam.com/works/work.php?ptype=view&idx=4030): 약100m 정방형 본체의 동쪽 공연장과 서쪽 디스커버리랩, 서로 다른 층 구성, 튜브·스텝 아트리움·게이트 아크를 설명한다. 공식 사진25장 중 실제 항공사진2, 구성 모형4, 축측 절개5, 정면6, 단면16·17을 직접 확인했다.
- [대한건축사협회 월간 건축사 회원작품](https://kiramonthly.com/1422): 간삼·안도 설계 크레딧이 있는 1층 평면과 단면. 북쪽 화살표가 오른쪽 위를 가리킨다. 평면의 왼쪽 위는 원본 서쪽 꼭짓점, 오른쪽 위는 북쪽, 오른쪽 아래는 동쪽이다. 좌하단의 지하철 접근부 절개도 원본의 비정방형 윤곽과 대응한다. 동선 설명만으로 튜브를 정남북 축에 고정하지 않고 이 평면을 우선했다.
- [운영기관 건축 소개](https://www.lgart.com/home/display/region/content/JSVFelN3a2tTendqd1FGWHRaQTNQNU15c2N4eW1wSkppNjdDSW9JK0xkTEFhND0=): 튜브 높이10m와 동·서 시설 구분. 원형/타원형 통로는 표면 창문이 아니라 빈 관통 공간이다.
- [LG사이언스파크 공식 공간 소개](https://www.lgsciencepark.com/KR/video_detail.php?idx=324&media_type=2&page=1): 튜브 길이80m와15도 기운 타원 단면. 내부 바닥은 수평이고, 기울어지는 것은 타원 단면이다.
- [운영기관 준공 옥상 사진](https://www.lgart.com/images/contents/img_visit_tab01_01.png): 타원형 상부 둘레벽, 낮은 별도 곡면, 노출콘크리트 테라스 입면의 큰 개구부, 원형 계단탑.
- [서울시 건축상](https://sca.seoul.go.kr/seoulhour/site/urbanArch/board/permanent/320): 공연장과 디스커버리랩을 하나의 수상작으로 설명하고 건축면적10,599.90㎡·연면적41,631.24㎡를 제시한다. 원본 OSM 윤곽 면적 약11,708㎡와 동일한 측량값으로 취급하지 않는다.

원본 이미지와 다운로드 HTML은 ignored `data/model-source/bespoke/next-review/lg-art-research/`에 연구용으로만 저장했다. 공개 GLB에는 이미지·사진 텍스처를 넣지 않는다. 실제 이미지는 저작권자의 작품이며 모델의 배포 권리와 별개다.

## 배치와 개별 요소

제작 입력의 `planTransform`은 세 개의 확정 방향 대응으로 평면의 픽셀 좌표를 기존 앵커의 동·북 좌표로 변환한다. 픽셀 좌표는 측량값이 아니다. 기존 윤곽과 앵커는 바꾸지 않으며 새 바운딩박스 중심으로 이동하지 않는다.

- 높은 공연장 본체와 낮은 서쪽 디스커버리랩의 지붕 판을 분리한다. 낮은 지붕 위에는 포장 테라스와 길쭉한 식재부가 있다.
- 튜브는 평면에서 대략(395,130)→(303,747)의 대각선이다. 원본 윤곽과 만나는 축은 약90.86m로 공식80m보다 길다. 튜브 자체는80m로 두고 양 끝은 유리 파사드 안의 진입 공간으로 남긴다. 윤곽-평면 정합 오차가 있으며 두 길이를 같은 실측이라고 주장하지 않는다.
- 큰 상부는 닫힌 타원 기둥이 아니다. 실제 항공사진의 내부 횡보·낮은 안쪽 지붕과 둘레벽을 따로 작성한다. 앞쪽 낮은 불완전 원호도 별도 요소다.
- 디스커버리랩 평면의 원형 계단 위치를 독립 원형 계단탑의 초기 정합 기준으로 사용한다. 실제 테라스 사진과 위치·높이의 추가 시각 검토가 필요하다.
- 북서쪽 아트리움은 높은 유리벽과 지상 콘크리트 띠, 여러 개의 별도 출입문으로 구성한다. 낮은 튜브 파사드와 잘린 지하철 접근부는 서로 다른 면이다.
- 디스커버리랩 갤러리 외벽, 공연장 서비스 입면, 높은 테라스 벽의 개구부는 각각 따로 작성한다. 가려진 서비스 입면의 세부는 미확정 상태로 표시한다.

## 치수의 한계와 검토

운영기관에서 확인되는 튜브 높이10m, 공식 공간 소개의80m·15도 외에 본체 높이20.8m, 낮은 지붕11.7m, 상부 타원31.2m, 창·루버·지붕 이음 간격 등은 단면과 사진의 비례 해석이다. 간삼 설명의3층/2층 구분, 간삼 메타데이터의B3·4F, 서울시 자료의B4·3F는 서로 달라 총 층수를 확정하지 않는다. 지하·공연장 내부·음향 설비·조경 전체를 재현했다고 주장하지 않는다.

실제 Blender MCP9878 세션으로 제작·저장·내보내기 한다. 최종 원본 사진과 같은 방향의 렌더, 반대 입면, 옥상, 튜브 입구를 root가 독립 비교하기 전에는 통합하지 않는다. 이 문서는 제작 근거이며 승인 기록이 아니다.
