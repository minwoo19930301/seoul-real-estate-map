# 사진·도면 대조에 따른 개별 모델 재작업

기존 주거·공공기관 생성기는 원천 외곽선에 반복 입면과 추정 색상을 입혔다. 파일별 해시나 색상이 달라도 실물에 맞춘 개별 모델이라는 뜻은 아니다. 기존 PR/소스 조사 결과는 [template-provenance.json](template-provenance.json)에 기록했다.

이번 반영은 **6개 현장의 14개 모델**이다. 전체 서울 건물의 재작업 완료를 뜻하지 않는다. 실제 Blender 4.5.11 LTS와 `mcp-for-blender`의 `execute_blender_code`를 사용했고, 사진과 렌더를 작성자와 별도로 대조했다. 첫 결과에서 다른 입면·큰 돔·반복 슬롯·잘못된 창 배치를 발견한 경우 수정 후 다시 비교했다.

| 현장 | 모델 | 개별 수정과 남은 한계 |
| --- | ---: | --- |
| 서울고속버스터미널 경부·영동선 | 1 | 높은 본동과 낮은 영동선 날개 분리, 경사 단부·승차장·캐노피. 높이는 추정이며 호남선/Central City는 별개로 유지. |
| 청량리 SKY-L65 | 4 | 공식 배치도에 따른 A~D 평면, 64/65/63/65층, 크라운·기단. 업무동과 별도 저층동은 소유하지 않음. 평면 추적과 높이는 실측이 아님. |
| 목동 하이페리온 | 5 | A/B/C의 높이·석재 축·큰 대각 구조, 주차장 기단, 현대백화점의 아치·원형 창·모서리 입구. 백화점에 잘못 적용된 210m 상자 교체. B동 높이 자료 충돌은 기록에 명시. |
| 메이플자이 210·211동 | 2 | 사진에 확인되는 서로 다른 정면, 옥상 라운지·연결교·설비실. 가려진 면과 나머지 27개 주거동은 개별 검토·재작업 대기. |
| 반포대교·잠수교 | 1 | 두 도로 높이, 잠수교 융기부, 교각·박스거더·분수 장치. 북측 진입부 하부구조 전체를 완성한 토목 모델은 아님. |
| 문화역서울284 | 1 | 남북으로 긴 평면과 동측 정면, 축소 교정한 돔·시계·벽돌/석재·귀빈실/RTO. 현대 서울역은 별개이며 현재 원천 데이터는 높이 없는 2D 외곽선. |

배포 GLB 합계는 29,112,940바이트, 547,533삼각형이다. 사진은 외부 출처 링크로 남기고, 새로 만든 검토 렌더만 이 저장소에 포함했다. [편집 가능한 Blender 원본](../../modeling/bespoke), [제작 스크립트](../../scripts/bespoke), [MCP 실행 기록](mcp), [개별 대조 기록과 해시](published-bespoke.json)를 함께 보존한다.

## 겹침과 실패 시 동작

원본 모델 파일을 덮어쓰지 않는다. 새 모델이 지형과 함께 실제로 그려진 뒤에만 지정한 원본 모델/건물 외곽선을 숨긴다. 한 복합 모델을 여러 동으로 교체할 때 화면 안의 새 동 하나가 실패하면 기존 복합 모델을 유지한다. 기존 랜드마크 우선순위는 보존한다. 백화점처럼 구획의 공통 층수가 엉뚱한 외곽선에 적용된 경우, 잘못된 모델을 정확히 지정해 대체한다.

## 남은 순서

1. 랜드마크
2. 400세대 이상 아파트
3. 대교·공원·문화재
4. 관공서
5. 100~399세대 아파트
6. 나머지 빌라·주상복합·오피스텔·소규모 아파트

[재작업 목록](rebuild-queue.jsonl.gz)과 [집계](rebuild-queue-summary.json)는 원래 113,248개 모델 레코드와 이번 추가 모델을 구분한다. 단지 하나가 여러 모델로 나뉘거나 대체 전후 레코드가 공존하므로 실제 건물 수로 해석하면 안 된다. 세대수·용도 근거가 없는 항목은 별도 확인 대기다.

다음 아파트 검토는 이미 반복 입면이 확인된 메이플101/104동, 같은 공식 항공사진으로 식별 가능한208/209/212/213동, 타워팰리스의 동·소유권 대응 순으로 진행한다. 모델/외곽선 개수만으로 실물 동 수나 정밀도를 판단하지 않는다.

## 검증

- Node 회귀 검사 13,714개, Python CI 검사 21개 통과.
- GLB의 유효 좌표·법선·지면 기준·앵커·SHA, 편집 원본 SHA, 실제 MCP 성공 기록 검사.
- 게시 중 메타데이터 교체 실패를 주입한 수동 검사에서 기존 파일과 메타데이터 복구 확인.
- 지도 브라우저 검사 6개 통과. 현장·이웃·기존 랜드마크·강제404·메이플29개 동을 확인했으며 [지도 화면](renders/map), `browser-check.json` 및 기존 landmark/reference 검사 기록으로 남긴다.
- 로컬 검증과 공개 배포는 별개다. 배포 완료 여부는 CI와 공개 release SHA/모델 해시로 확인한다.
