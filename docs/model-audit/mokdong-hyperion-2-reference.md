# 목동 하이페리온2차 — 개별 주거동 제작 검토

단지: 서울 양천구 목동961 / 오목로300. 관리코드 A15805111, 공동주택576세대/4동. 201140세대,202156세대,203124세대,204156세대. 업무205·206은 이번 범위 외이며 종전6동 GLB는 root가 주거/업무로 원본삼각형 분리하여 보존한다. 1차 A15805114와 별개이고, 1차의 기존 모델·높이·헬리패드 형태를 재사용하지 않았다.

  - aurum-4: 지상 준공 전경, 석재 서비스창줄과 녹청 창띠, 지붕의 개방된 짧은 판들. 사진 동번호는 명시되지 않는다. 주변 배치와 높이로 주거동임을 확인하되 정확 카메라/개별번호 정합은 추정이다.
  - aurum-3: 중정 재진입면의 넓은 유리창/가운데 작은 서비스창, 하부 어두운 수평띠와 석재 기둥. aurum-1/2는 동 사이 중정의 다른 시점이다.
  - aurum-5: 전면 업무205/206의 둥근 옥상캡이므로 주거 지붕 근거에서 제외.
- Summit Facade 외피 설계/감리사: https://www.sfacade.net/dongtan-hyperion-1
  - consultant-0: 중정 실제 준공사진. 세로 석재 띠와 창 돌출프레임을 확인.
  - consultant-1: 주거동 지붕 근접 실제사진. 낮은 날개 옥상, 높이 올라온 중앙 석재 구조물, 사선 두 보와 횡보. 옥상 촬영 지점/동번호 표기 없음. 북쪽에서 남쪽을 보는 배치 가설로 비교카메라 작성하되 위치 확정이 아님.
  - consultant-2: 실내만으로 동번호 식별불가, 형상근거 제외.
  - consultant-3: 업무동 앞모습, 주거 제작 범위 제외.
  - 본문 '49 Story / Kyunggi Province'는 정확대장과 불일치하므로 높이/층수/주소 근거에 사용하지 않음. 사진의 실제외관이 AURUM와 일치하는 부분만 채택.
- 서울시 건축물대장 원본: https://data.seoul.go.kr/dataList/OA-22424/S/1/datasetView.do
  - source-register.json는 목동961/오목로300 정확일치7행. 201:37층122.8m,202:41층134.55m,203:33층109.65m,204:41층134.55m. 법정높이 기준점/옥상장식 포함 여부 원문에 명시되지 않음. 모델은 이값을 보수적 전체높이 근사로 사용하며 '실측 옥탑 끝 높이'라 주장하지 않음.

## 근거의 한계
주거4동의 실제 높이차, 개별 윤곽, 석재/창의 큰 면분할, 중앙 옥탑 형태를 구현한다. 번호별 각 입면을 직접 적시한 건축가 상세도는 확보하지 못했다. 같은 단지 내 반복된 창 모듈은 관측사진과 일치하는 범위에서 공유하지만, 모든 면을 같은 유리격자로 처리하지 않는다. 보이지 않는 지붕설비·내부·조경은 재현대상이 아니다. 모든 입력사진은 로컬 검토용이며 .blend/GLB에 삽입하지 않는다.

## 재생성
이 폴더의 authored recipe.json과 build.py는 독립적이다. Blender4.5.11에서 build.py를 실행하면 .blend와4개의GLB 및bundle을 만든다. prepare.py는 동봉된 source-buildings.json에서 입력을 다시 구성하는 선택 단계이며 Shapely가 필요하다. 사진 다운로드나 외부DB접속은 빌드에 필요 없다. 실제 MCP 실행 로그는 mcp-build-v*.json, 비교뷰는 review-v*.png에 보존한다.

## v3 외관교정
AURUM4와 consultant1의 끝면 서비스창을 3열로 교정했다. 가운데는 밝은 녹청색, 외측2열은 작고 짙은 서비스창이다. 중앙 옥탑은 넓은 유리칸이 아닌 석재 몸체의 좁은 세로 홈과 두꺼운 외곽띠이며, 사선 쌍보는 깊은 판형 단면으로 재구성했다. 석재 끝면만 패널줄을 추가하고 중정의 넓은 유리 입면에는 넓은 양끝 석재 띠를 별도로 두었다.

카메라 한계: SE-source라는 비교뷰 이름은 원본촬영위치 확정을 뜻하지 않는다. 북쪽 Y끝면이 보이는 AURUM4와 비교하기 위해 NW-ground-photo를 별도 추가했다. 건물번호가 없는 사진으로 정확 지점을 확정하지 않았으며, 후면/남측 뷰는 모델 전체 배치검사용이다.

## v4 마지막검사
동일 높이의 옥상 난간 상면이 모서리에서 겹쳐 검은 사각점으로 보이던 부분은 평면 union으로 제거했다. 낮은 날개 지붕 < 높은 석재 끝벽 < 중앙 석재 옥탑 < 사선쌍보의 순서를 consultant1과 다시 대조했다. 모델 상대단차는 각각 대장높이-9.2m/-7.55m/-3.7m/최고점이며, 이 중간값들은 사진비례 해석이고 측량치가 아니다. roof-step-review.json에 동별값을 남겼다.
