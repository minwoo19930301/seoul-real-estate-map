# 메이플자이 208·209·212·213동 개별 재작업

이 문서는 첫 배치의210/211동과 별개인 네 동의 제작 근거다. 기존31개 public GLB와 앵커는 보존한다. 이번 대상은 번호 배치도, 서로 반대 방향의 공식 공사 항공사진, 공식 준공사진을 대조해 구성했으며, 모든 면·층수·치수를 검증했다는 뜻은 아니다.101/104동은 특정 실사진 입면을 확정하지 못해 재생성하지 않는다.

## 근거와 동 식별

사진 파일은 `/tmp/maple-audit-reference/`와 `/tmp/maple-next-reference/`에만 둔다. 사진·텍스처를 repo나 GLB에 포함하지 않는다. `/tmp/maple-next-reference/208-209.jpg`, `212-213.jpg`, `feb-four.jpg`는 원본의 검토용 부분 확대다.

## 제작과 검토

`maple_next_prepare.py`는 개별 면/옥상 프로그램만 작성한다. `maple_next_blender.py`는 실제 MCP9878 세션에서 네 동을 각각 내보내고 조립된 편집 장면 `maple-next-towers.blend`를 저장한다. 반복층·창·핀·패널 메시 생성 함수는 공유하지만, 네 동의 면 배치·두 팔 높이·옥탑을 하나의 분류로 선택하지 않는다.

첫 렌더에서 일부 패널이 roof edge를 넘고 설비실과 겹치는 것을 확인해, 각 팔의 길이 안에 별도 위치·폭으로 조정했다. 모든 패널의2D 모서리가 해당 전체 footprint 안에 있는지 확인했다. 사진과 같은 두 외면이 읽히도록 동측 카메라도 조정했다. 이는 제작 중 수정이며 승인 기록이 아니다.

검토 대상은 동별 `208_east/west/roof.png`부터 `213_east/west/roof.png` 및 MCP viewport다. root가 실제 출처와 최종 렌더를 대조한 승인 기록은 `published-bespoke.json`에 저장하며 해당 파일 해시와 일치하는 모델만 공개 replacement에 포함한다. 남은23개 기존 주거동을 이번 개선으로 검토 완료 처리하지 않는다.

동측 비교 렌더에서 어두운 면이 실사진과 반대로 보이는 것을 확인했다.208/210/211의 같은 높이 지붕 중심을 대조하면 이 사진은 동측에서 보며 북쪽이 이미지 오른쪽에 대응한다. 이에208의 어두운 면을e2→e1,212를e4→e3,213을e4→e3으로 정정했다. 큰 흰 그리드를 임의로 커튼월화하지 않도록 최종 입력과 면 도식을 함께 갱신했다.

## 옥탑과 하부 재검토

독립 검토에서209 북동 고층 팔/남서 낮은 팔,213 남서 고층 팔/북동 낮은 팔과208 e1·212 e3의 어두운 면 배치를 재확인했다. 그 형태는 유지했다. 설비실의 작은 세로 슬롯·상부 사각 개구부·폭이 넓은 환기 패널 및 각 방의 높이가 다른 캡 턱은 입력의 `plants[].apertures/capStep/capSide/openingBasis`로 따로 작성했다. 사진상 크기·배치의 해석이며 실제 개구부 시공 상세나 치수가 아니다. 기존 환기 패널이 벽 안쪽을 향해 보이지 않던 생성 오류도 바깥 법선으로 수정했다.209의 높은 설비실6.0m,213의5.6/5.1m 역시 보이는 창층 대비 비율의 추정값이다.

근거 없이 반복되던 지상 모서리 기둥은 모두 제거했다.209·212·213은 보이지 않는 지상층을 보수적인 막힌 질량으로 남겼으며 정확한 출입구·필로티 재현으로 취급하지 않는다.208만 번호가 보이는 실제 석재 문틀·갈색 슬랫·천장 루버를 개별 작성했다. 출입구 방향과 절대 치수는 여전히 추정이다. 이 네 동은 확인 가능한 면의 개선이며 전체 외관 검증 완료가 아니다.

208 출입구 확대 검토에서 처음의 슬랫 배열이 깊이 방향으로 겹쳐 한 줄로 보이는 오류를 확인했다. 준공사진의 전면 슬랫 스크린·넓은 중앙 석재 벽체·두 개의 문틀 공간이 읽히도록 수정하고 우편함 구획 및 천장 스트립을 추가했다. 사진이 보여주지 않는 전체 입구 평면은 복원하지 않았다.
