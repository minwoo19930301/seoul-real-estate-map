## 식별과 한계

고덕 초기조사팩의 송파구/2678세대/35동은 다른 단지 자료가 섞인 오류라 사용하지 않았다. 공개 고정자료와 대장의 강동구 동남로79길26/고덕동499/1142세대/14동을 사용했다. 추가7개 동은 공식 대표점300m 이내의 유일한 동번호 후보와 해당 주소의 주건축물 대장을 맞췄다.14동 세대수 합1142를 확인했다. 지적 경계에 의한 소속 증명은 없으며 추론 식별임을 기록한다.105동은 OSM19층52m 대 대장18층52.7m 충돌을 보존하고 대장높이로 적용했다.

개포는35개 주거동 식별목록을 사용한다. 대표405의15층 패턴을7~35층 대상에 전체 높이 변환하므로 각 동의 창문·층수 패턴이나 오목한 윤곽이 실제와 같다는 뜻이 아니다. 후면·방향·일부 치수와 지붕면은 추정이다. 두 단지 모두 공용시설·조경·실내까지 완료했다는 뜻은 아니다.
