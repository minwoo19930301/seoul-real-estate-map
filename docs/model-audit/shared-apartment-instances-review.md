대표의 창문·층 패턴, 지붕과 평면 형태는 반복된다. 기존 위치·방향 및 전체 가로·세로·높이만 변환했으므로 각 동의 실제 외곽선이나 층별 입면을 개별 재현한 것은 아니다. 파크리오102·104·119·120은 경계,209·210은 식별 충돌이 있어 기존 모형을 보존했다.

## 구현과 검증

같은 GLB경로와SHA는 한 번 읽고 파싱한다. 건물마다 독립된 변환과 번호 가시성을 가지며, 메시와 재질을 공유한다. 마지막 사용 건물이 해제될 때만 GPU자원을 해제한다. 네트워크 오류는1초·2초 간격으로 최대2회 재시도하고, 체크섬·치수·파싱 오류는 반복하지 않는다.

기존 개별 모델과 원본 파일은 보존했다. 파크리오 기존 복합 모형의51개 대상동을 원본 삼각형 그대로 분리하고9개 독립 모형과5개 잔여 원천 건물을 유지했다. 각 새 모델은 그 동에 해당하는 fallback만 대체한다.

- Node 전체13,824개 통과; Python 높이·publisher·queue50개 통과.
- 브라우저6개 통과: 두 단지의 정상표시, 공유GLB404시 동별fallback, 해당fallback도404일 때 원천지도 복구.
- 브라우저에서 동시 복제들이 같은 geometry/material을 공유하고 번호를 숨기는 것 확인. 각 단지 대표 파일 요청은1회.
- 대표 모델만 원본 사진과4방향 렌더를 대조했다. 복제 배치는 자동 검사와 아래 지도 표본으로 확인했다.
