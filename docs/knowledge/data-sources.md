# 자료별 역할과 출처

이 문서는 2026-09-10~11의 [48종 공개 자료 조사](../APARTMENT_SOURCES.md)와 [적재 결과](../APARTMENT_SOURCES_IMPORT.md)를 읽기 위한 안내입니다. 자료마다 대상 단위와 갱신 시점이 달라, 같은 단지 화면에 표시된 숫자도 바로 비교하거나 합산하지 않습니다.

| 주제 | 이 프로젝트에서 조사한 자료 | 읽을 때 구분할 점 |
|---|---|---|
| 단지 기본정보 | 서울시 공동주택, K-apt, 한국부동산원 단지 식별정보 | 단지코드·관리단위가 서로 다를 수 있습니다. 좌표는 단지를 대표하는 점이며 개별 동의 출입구가 아닙니다. |
| 건물·인허가 | 건축물대장, 주택인허가 동별개요, 도로명주소 건물DB | 필지·동·대장 행은 같은 단위가 아닙니다. 층수와 높이, 인허가 기록과 현재 건물 상태도 분리합니다. |
| 거래·가격 | 서울시 실거래·전월세, 국토교통부 공동주택 공시가격 | 거래 종류·기준연도·면적을 보존합니다. 서로 다른 의미의 가격을 하나의 현재 가격으로 합치지 않습니다. |
| 관리비·주차·에너지 | 공동주택 관리비, 자치구 주차면수, 건축HUB 에너지 | 원문이 단지 전체 합계인지 확인합니다. 현재 지도 관리비는 세대당 금액이 아닌 단지의 최근 월 부과 합계입니다. |
| 정비사업 | 서울도시공간포털 사업장·정비구역, 정비사업 정보몽땅 | 사업장과 지정 구역은 별도 레이어입니다. 도형에 포함된 사실만으로 개별 건물의 권리·진행 단계를 확정하지 않습니다. |
| 공공주택 | SH·LH·HUG 목록 | 주소·식별자가 없는 행은 연결을 보류합니다. 목록 적재와 지도 표시를 구분합니다. |

## 수집에서 표시까지

1. 출처 URL, 제공기관, 기준 시점, 요청 방식, 이용조건, 파일 크기와 SHA-256을 manifest에 기록합니다.
2. 원문 열과 행은 보존하고, 자료별 필터를 기록해 서울 범위를 추립니다.
3. 형식·행 수·파일 지문·DB 무결성을 검사한 뒤 파생 DB를 교체합니다.
4. 연결 키와 모호성을 점검한 자료만 지도에 연결합니다. 연결되지 않은 행은 버리지 않고 별도로 남깁니다.
5. 팝업에는 값의 단위와 출처를 표시합니다. 수집 성공을 구현 완료로 표시하지 않습니다.

원본 조사에는 공공누리 제4유형 자료와 재배포 조건이 확인되지 않은 자료도 있습니다. 이 저장소는 해당 원자료를 포함하지 않습니다. 자료별 이용조건과 실제 사용 범위는 [출처 목록](../APARTMENT_SOURCES.md)을 기준으로 확인합니다.
