# 지도에 보이는 숫자를 읽는 방법

## 가격·관리비·건축 정보의 기준을 먼저 본다

같은 단지 팝업에 여러 자료를 모아도 측정 대상과 기준 시점은 서로 다릅니다. 실거래는 신고된 개별 계약, 공시가격은 해당 기준연도의 평가 자료, 관리비는 부과 기간과 관리 단위가 있는 기록입니다. 이를 같은 시점의 같은 세대에 대한 값으로 합치지 않습니다.

비교할 때는 원본 출처, 기준일, 면적·층·거래 유형, 단지 또는 필지 연결 근거를 함께 확인합니다. 지도에 자료가 없다는 표시는 거래나 건물이 없다는 뜻일 수도 있지만, 자료 범위 밖이거나 식별자 연결에 실패한 결과일 수도 있습니다. 누락을 0으로 바꾸지 않습니다.

현재 지도에 연결된 자료와 적재만 된 자료는 [적재·연결 기록](../APARTMENT_SOURCES_IMPORT.md)에 구분되어 있습니다. 예를 들어 주소가 없는 목록은 단지 이름만 보고 붙이지 않습니다.

## 지면 고도와 건물 높이는 다르다

표고점은 원본이 기록한 지면 고도이며, 건물 높이는 건물 자체에 관한 값입니다. 클릭한 위치에서 보여주는 가까운 원본 표고점과 선택 지점 사이에는 거리가 있습니다. 그 값을 클릭 지점의 실측 고도로 바꿔 설명하면 안 됩니다.

2.5D 지형 표면은 등고선·표고점 사이를 보간한 결과입니다. 원본을 빠짐없이 적재해도 모든 지점의 지면을 측량한 것은 아닙니다. 공사 이후 변화, 옹벽, 계단과 교량 상판을 정밀 복원한 모델로 사용하지 않습니다.

화면의 지형 강조 배율은 높낮이를 보기 위한 표현입니다. 저장된 표고점 숫자나 원본 건물 높이에 배율을 곱하지 않습니다. 자료가 부족한 영역의 회색 표시와 원본 조회 거리도 함께 봅니다.

## 원본 기록과 모형의 추정을 나눈다

일반 건물 DB는 높이가 없으면 누락 상태를 유지합니다. 별도 GLB 모형에서는 층수·대장 기록·공개 자료를 바탕으로 높이나 외형을 추정한 부분이 있습니다. 이 모형을 원본 DB의 실측 건물처럼 설명하지 않습니다.

높이가 기록돼 있다는 것과 독립 실측으로 정확성이 확인됐다는 것도 다릅니다. 층수는 층고·필로티·지붕 구조 등의 가정 없이 정확한 높이로 바꿀 수 없습니다. 지도 위 장식 나무와 크기 비교용 사람·차량은 실제 관측 대상이 아닙니다.

## 면적의 단위를 섞지 않는다

| 표시 또는 자료 | 의미 |
| --- | --- |
| 지도 외곽선 면적 | 도형을 미터 기반 좌표계에서 계산한 수평 면적; 지붕 윤곽일 수 있음 |
| 건축면적·대지면적·연면적 | 건축물대장이 제공하는 별도 속성 |
| 전용면적 | 개별 세대·호에 관한 속성 |

건물 외곽선 면적으로 전용면적을 계산하거나, 화면 범위에 잘린 도형을 건물 전체 면적으로 저장하지 않습니다. 경위도 좌표에서 계산한 면적에 단순히 m² 단위를 붙이지도 않습니다.

더 자세한 기준은 [아파트 데이터와 높이·면적](../APARTMENT_DATA.md), [등고선 전수 감사](../CONTOUR_AUDIT.md), [주거 모형 조사와 추정 범위](../RESIDENTIAL_SURVEY.md), [사람 시점과 정적 모형](../MOBILITY.md)에서 확인할 수 있습니다.
