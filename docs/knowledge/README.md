# 부동산 데이터 지식

서울의 아파트·건물·정비사업·생활 인프라를 지도에 연결하며 쌓은 조사와 구현 기록을 주제별로 정리했습니다. 아래 내용은 이 저장소의 공개 자료 조사·적재·감사 결과를 바탕으로 하며, 개인 재무 기록이나 상담 내용은 포함하지 않습니다.

| 읽을거리 | 다루는 질문 |
|---|---|
| [자료별 역할과 출처](data-sources.md) | 단지·거래·공시가격·관리비·정비사업 자료가 각각 무엇을 설명하는가? |
| [단지·동·필지를 연결하는 기준](identifiers-and-joins.md) | 이름이나 주소가 비슷한 자료를 어디까지 같은 대상으로 볼 수 있는가? |
| [지형·높이·면적 읽기](reading-map-data.md) | 지도에서 보이는 높이와 원본 기록, 건물 외곽선 면적은 어떻게 다른가? |
| [출처 기록과 갱신](provenance-and-refresh.md) | 새 자료를 받아 무엇을 검증하고 어떻게 변경을 추적하는가? |

조사 수치에는 각 원문에 적힌 기준일이 적용됩니다. 현재 운영 기능은 [프로젝트 README](../../README.md), 자료의 실제 연결 범위는 [적재 결과](../APARTMENT_SOURCES_IMPORT.md), 변경 이후의 주거 모형 연결은 [주거 전수 조사](../RESIDENTIAL_SURVEY.md)를 따릅니다. 조사 당시의 미완료 계획을 현재 구현으로 오해하지 않도록 원문과 함께 읽습니다.

원자료의 다운로드 가능 여부와 재배포 조건은 별개입니다. 원본 CSV·ZIP·SQLite와 개인 저장 위치는 이 지식 문서에 포함하지 않았으며, 출처 링크와 수집·검증 방법을 제공합니다.
