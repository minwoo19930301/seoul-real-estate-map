# 브이월드 외 서울 공개 건물 자료 조사

확인일: 2026-09-08. 공개 웹 지도에서 일반 조회에 쓰이는 페이지·스크립트·서비스를 확인했습니다. 로그인·차단 우회·BrightData 프록시는 사용하지 않았습니다. 건물 도형을 받은 것은 시청 주변의 **서울도시공간포털 3건 + S-MAP 3건**뿐입니다. 운영 건물 DB를 바꾸거나 서울 전체를 수집한 상태가 아닙니다.

## 결론

**무료·무키로 읽을 수 있는 실제 외곽선과 건물관리번호의 조합은 발견했습니다.** 현재 Overture 원본에 없는 주소 연결 정보를 제공하므로 대장 연결을 위한 후보가 됩니다. 그러나 조사한 두 건물 레이어에는 높이 필드가 없습니다. 따라서 **같은 건물 ID에 공식 대장 높이까지 붙은 완성 자료를 확보했다는 결론은 낼 수 없습니다.**

서울도시공간포털의 건물 전체 수집·재배포 허용도 이번 조사에서 확인되지 않았습니다. 공개 쿼리 성공이나 최대 응답 수는 기술적 기능의 증거이며, 개별 데이터의 대량 이용허락을 증명하지 않습니다. 현재 단계는 외곽선·식별자·주소 샘플의 확보 및 대장 연결 가능성 검토입니다.

| 서비스 | 실제 확인한 제공 내용 | 높이와 식별자 | 현재 판단 |
|---|---|---|---|
| 서울도시공간포털 | ArcGIS `THEME_SHP_BLDG` Polygon 3건, 주소·층수·용도 | `BLDG_MGRNU` 25자리, `ADDRESS` 19자리. 높이 필드 없음 | 공식 외곽선·주소 연결 후보. 자료 시점과 전체 이용조건 확인 필요 |
| S-MAP | WFS `seoul:tl_spbd_buld` MultiPolygon 3건 | `bd_mgt_sn` 25자리, 법정동·지번·층수. 높이 필드 없음 | 주소 기반 연결 후보. 표본의 작업일이 오래되어 현행성 확인 필요 |
| 서울부동산정보광장 | 공개 지도 스크립트에 필지·행정경계 WFS, 종합 부동산 정보 조회 | 공개 화면은 PNU 기반. 이번 조사에서 높이+건물 외곽선+공통 건물 ID 응답은 확보하지 못함 | 현재 병목의 해결 자료로 입증되지 않음 |
| S-MAP 오픈랩 3D 원본 | 공식 제공 FAQ에 실외 입체모형·DEM·DSM·점군·건물높이 공간정보 목록 | 신청 및 검토 절차가 있는 별도 원본 제공 경로 | 즉시 익명 전체 다운로드 경로로 볼 수 없음 |

## 보존한 6개 건물 표본

원본 응답과 스키마는 [`data/sources/public-map-samples-2026-09-08/`](../data/sources/public-map-samples-2026-09-08/)에 있습니다. [`manifest.json`](../data/sources/public-map-samples-2026-09-08/manifest.json)에 실제 요청 URL, GET 방식, 바이트 수와 SHA-256을 기록했습니다.

### 서울도시공간포털

- 원본: [`urban-buildings-sample.json`](../data/sources/public-map-samples-2026-09-08/urban-buildings-sample.json), 스키마: [`urban-buildings-meta.json`](../data/sources/public-map-samples-2026-09-08/urban-buildings-meta.json).
- 공개 지도: <https://urban.seoul.go.kr/view/map/main.html>.
- 지도 스크립트: <https://urban.seoul.go.kr/content/map/mapInit_.js>. 여기서 사용하는 공개 프록시와 ArcGIS 서비스 경로를 따라 조회했습니다.
- 대상 레이어는 `UPIS/20200526_WFS/MapServer/86`, 이름은 `THEME_SHP_BLDG`입니다. 원본 좌표계 EPSG:5174이며 표본 응답은 `outSR=4326` 변환 결과입니다.

| OBJECTID | BLDG_MGRNU | 주소 단서 | 도형 정점 수 |
|---:|---|---|---:|
| 31887845 | `1114010300100310019000001` | 태평로1가 31-19, 무교로 17-25 | 5 |
| 31892956 | `1114010300100310000019224` | 서울특별시청, 태평로1가 31 | 34 |
| 31892958 | `1114010300100250000019057` | 태평로1가 25, 세종대로 124 | 21 |

세 표본 모두 실제 Polygon 좌표를 받았습니다. `ADDRESS`는 예를 들어 `1114010300100310000`과 같은 19자리 값이며 `BLDG_MGRNU`와 별도 필드입니다. 면적·층수·사용연도 등의 속성도 있지만 **미터 단위 건물 높이 필드는 없습니다.** 층수를 높이로 바꾸지 않았습니다.

공개 서비스 메타데이터에는 `Map,Query,Data`, 최대 응답 10,000건이 표시됩니다. 페이지 기반 조회는 실제로 `Pagination is not supported` 오류를 반환했습니다. 표본 확보에는 좁은 범위에서 ID만 조회한 뒤 3개 `objectIds`를 지정했습니다. 이는 서울 전체 수집을 수행하거나 권한을 인정한 것이 아닙니다.

자료의 게시일·전체 갱신일은 해당 레이어 메타데이터에 없었습니다. 서비스 경로의 `20200526`을 데이터 기준일로 단정하지 않습니다. `SAYONG_YEA=1926`, `DBJSFLOOR=7`인 시청 표본은 특정 구청사 또는 오래된 개체를 가리킬 수 있어 현재 신청사 기록과 자동 결합하면 안 됩니다. `SAYONG_YEA`는 데이터 다운로드일이나 갱신일이 아닙니다.

### S-MAP

- 원본: [`smap-buildings-sample.json`](../data/sources/public-map-samples-2026-09-08/smap-buildings-sample.json), 스키마: [`smap-building-schema.xml`](../data/sources/public-map-samples-2026-09-08/smap-building-schema.xml).
- 공개 지도: <https://smap.seoul.go.kr/>.
- 일반 지도 조회용 `imageProxy.do?svc=2D&param=...` 경로의 WFS를 사용했습니다. `maxFeatures=3`과 시청 주변 작은 bbox를 지정했습니다. 정확한 URL은 manifest에 있습니다.
- `DescribeFeatureType`로 `tl_spbd_buld`, `tl_spbd_buld_2`, `area_shp` 정의를 확인했습니다. 앞의 두 레이어에는 층수와 건물관리번호가 있고 높이는 없습니다. `area_shp`는 모델 ID와 사용자 이름·도형만 있으므로 이를 대장 높이 데이터로 간주하지 않았습니다.

| Feature ID | bd_mgt_sn | 주소·명칭 단서 | 지상층수 | 도형 정점 수 |
|---|---|---|---:|---:|
| `tl_spbd_buld.44302` | `1114010400100160000019259` | 을지로1가 16 | 13 | 9 |
| `tl_spbd_buld.44303` | `1114010100100210003019164` | 무교동 21-3, 정오빌딩 | 7 | 10 |
| `tl_spbd_buld.44304` | `1114010100100240002019195` | 무교동 24-2, 휘닉스빌딩 | 13 | 7 |

주소의 동 이름은 추측으로 붙이지 않았습니다. 서울도시공간포털의 공개 검색용 `POST /api/map/emd/getList.json`에 `sggCd=11140`을 전달하여 `11140101=무교동`, `11140103=태평로1가`, `11140104=을지로1가`를 확인했습니다. [코드표 원본 응답](../data/sources/public-map-samples-2026-09-08/urban-junggu-legal-dongs.json)을 함께 보존했습니다.

같은 3개 feature ID의 [날짜 필드 원본 응답](../data/sources/public-map-samples-2026-09-08/smap-building-dates.json)을 추가 확인했습니다. `opert_de`는 각각 `20100620`, `20100901`, `20100901`이고 `ntfc_de`는 모두 `20110729`였습니다. `compet_de`, `mvmn_de`는 null입니다. 이는 오래된 속성이 남아 있다는 단서이며 정확한 도형 제작일·최종 검증일은 입증하지 않습니다. WFS 응답의 2026년 `timeStamp`는 응답 생성 시각입니다. 지도 메뉴에 최신 3D 연도가 표시된다고 이 별도 WFS 레이어도 최신이라는 뜻은 아닙니다.

## 식별자와 대장 연결에서 남은 문제

도로명주소 건물관리번호 `bdMgtSn`은 대장관리번호나 Overture GERS와 다른 체계입니다. 주소정보 도움센터는 건물관리번호가 생성 후 주소 변경에도 유지될 수 있어 앞부분을 현재 주소 코드로 곧바로 해석할 수 없다고 설명합니다. 일반 주소 API가 복수 건물관리번호 중 하나만 반환할 수도 있습니다. [공식 건물관리번호 설명](https://eng.juso.go.kr/addrlink/qna/qnaDetail.do?bulletinRefSn=75485&currentPage=411&keyword=&noticeMgtSn=75485&noticeType=QNA&noticeTypeTmp=QNA&page=&searchType=), [복수 건물관리번호 안내](https://www.juso.go.kr/addrlink/qna/qnaDetail.do?bulletinRefSn=127709&currentPage=58&keyword=&noticeMgtSn=127709&noticeType=QNA&noticeTypeTmp=QNA&page=&searchType=).

따라서 이번 표본의 25자리 식별자를 CSV의 다른 식별자와 같다고 가정하지 않습니다. 주소·지번·동명으로 후보를 찾더라도 동일 대지의 여러 동, 부속 건물, 재건축·증축·이전 자료를 구분해야 합니다. 같은 PNU나 도로명주소에서 높이 하나를 모든 외곽선에 복제하는 방식은 사용하지 않습니다. **외곽선과 높이가 같은 실제 건물이라는 근거를 확보해야 연결을 확정할 수 있습니다.**

독립 검토에서 확보된 CSV를 6개 표본의 법정동·지번으로 대조한 결과, 주소 후보는 찾았지만 **공통 개체 키로 확정한 높이 연결은 0/6건**입니다. 구체적으로 시청 태평로1가 31에는 1926년·7층·높이 0인 구관 쪽 기록과 2012년·13층·53.5m인 신관 기록이 함께 있습니다. 공개 지도 표본은 1926년·7층이므로 같은 주소라는 이유로 신관의 53.5m를 붙이면 잘못된 높이가 됩니다. [6개 표본의 CSV 후보 검사 결과](../data/sources/public-map-samples-2026-09-08/register-public-sample-candidates.json)는 후보와 확정 연결을 구분해 보존했습니다. 높이 0·공란은 확보된 실제 높이로 취급하지 않았고 어느 후보도 운영 외곽선에 대입하지 않았습니다.

## 이용조건과 대량 제공의 현실적인 판단

### 공개 ArcGIS·WFS

서울도시공간포털 건물 레이어의 `copyrightText`와 `description`은 비어 있습니다. 표본 응답과 스키마에는 개별 공공누리 유형이나 전체 데이터의 재배포 조건이 표시되지 않았습니다. S-MAP WFS의 `Fees=NONE`, `AccessConstraints=NONE` 역시 서비스 메타데이터일 뿐 개별 원본의 자유 재배포 라이선스를 확정하는 근거로 사용하지 않았습니다.

[서울시 공식 저작권 정책](https://www.seoul.go.kr/helper/copyright.do)은 공공누리 표시가 없는 자료는 관리 담당자와 사전 협의하도록 안내합니다. 이 정책을 근거로 “전체 수집이 금지돼 있다”고 단정한 것은 아니며, **이번 확인 범위에서 전체 수집·재배포 허용이 입증되지 않았다는 뜻**입니다.

[오픈랩 약관](https://openlab.eseoul.go.kr/) 제11조는 API·파일의 출처 표시 이용을 원칙으로 하면서 제3자 자료는 별도 조건을 적용합니다. 같은 사이트의 저작권 정책은 개별 KOGL 표시를 확인하고 미표시 자료는 담당자에게 확인하도록 안내합니다. 이 일반 문구만으로 S-MAP의 모든 레이어나 별도 공개제한 3D 원본을 같은 조건으로 가져갈 수 있다고 해석하지 않았습니다.

### S-MAP 3D 원본 신청

오픈랩의 공개 FAQ에서 최신 첨부 **「3D 제공 관련 FAQ 모음집(2026.04.)」**를 받았고 7쪽을 직접 확인했습니다. 게시글 날짜는 2025-08-18이지만 첨부 등록일은 2026-06-08입니다. [공식 FAQ 첨부](https://openlab.eseoul.go.kr/gallery/downloadFiles.do?file_download=8AjbN6KX0BGEs0V3TYr1Hg), [보존한 원본 PDF](../data/sources/public-map-samples-2026-09-08/openlab-3d-faq-202604.pdf).

안내문은 S-MAP 3D 원본을 공개제한 공간정보로 분류합니다. 학술 연구는 사용 신청과 보안·연구 증빙을 검토하고, 민간 사업자는 먼저 보안심사를 거쳐 적합 판정 후 사용 신청을 하는 절차입니다. 목록에는 실외 입체모형, 건물높이 공간정보, DEM·DSM·LiDAR 등이 포함되어 있습니다. 신청 문의는 서울시 공간정보과 공간정보운영팀 **02-2133-2852**입니다. 제공 목록의 건물높이 공간정보가 대장 높이와 동일한 의미이거나 현재 CSV와 같은 ID라는 사실은 이 FAQ만으로 확인되지 않습니다.

즉, 브이월드 외의 **공식 별도 제공 경로는 있습니다.** 다만 로그인 없이 즉시 서울 전체 건물 외곽선·공식 높이·연결 ID를 내려받을 수 있는 완성 대안까지 확보한 상태는 아닙니다.

### BrightData의 역할

BrightData 키는 사용하지 않았고 현재 샘플 확보에는 필요하지 않았습니다. 수집 도구가 바뀌어도 원본에 없는 높이·연결 ID가 생기거나 개별 자료의 이용조건이 바뀌지는 않습니다. 공개 페이지 수집을 자동화할 때 도움을 줄 수 있지만, 현재 남은 핵심은 **높이와 도형의 같은 개체 연결·자료 시점·원본 이용조건**입니다.

2026-09-08에 확인한 [Web Unlocker 공식 가격표](https://brightdata.com/pricing/web-unlocker)는 월 5,000회 무료 요청과 사용량 과금 $1.50/1,000회를 안내합니다. 모든 BrightData 상품이 같은 한도를 쓰는 것은 아니므로 실제 사용할 계정·상품의 한도를 확인해야 합니다. [REST API](https://docs.brightdata.com/api-reference/rest-api/unlocker/unlock-website)는 API 키와 `zone`을 요구합니다. 현재 키·zone은 제공받지 않았고 크롤러도 구현하지 않았습니다.

후속 수집은 먼저 재사용 가능한 무료 일괄 파일을 사용하고, 필요한 공개 페이지가 정해진 경우에만 BrightData를 연결합니다. 그때 원문 캐시·중단 후 재개·요청 수 상한을 적용해 같은 페이지를 반복 수집하지 않는 구성을 사용합니다. 이는 후속 구현 계획이며 현재 작동하는 기능으로 표시하지 않습니다.

이번 작업은 조사 문서와 샘플 manifest의 출처 보완으로 끝냈습니다. 새 크롤러, 대량 수집, 운영 DB 교체, 외부 게시·배포는 수행하지 않았습니다.
