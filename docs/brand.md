# Seoul Real Estate Map 표식

높이가 다른 두 건물과 그 아래 이어지는 등고선을 결합한 벡터 표식입니다. 특정 건물이나 실제 지형을 나타내지는 않습니다. 기존 지도 화면의 잉크색 `#26343b`와 등고선 갈색 `#9c532b`를 사용합니다.

- 기본 파일: `/brand/seoul-real-estate-map.svg` (`public/brand/seoul-real-estate-map.svg`)
- 파비콘: `/favicon.svg` — 같은 도형을 사용합니다.
- 크기: `40 × 40` viewBox, 투명 배경. 헤더에서는 24–38px를 권장합니다.
- 독립 이미지 대체 텍스트: `Seoul Real Estate Map — 건물과 등고선`

서비스명이 바로 옆에 표시되는 헤더에서는 `<img src="/brand/seoul-real-estate-map.svg" width="38" height="38" alt="" aria-hidden="true">`로 중복 낭독을 피합니다. 서비스명 없이 사용하는 이미지에는 위 대체 텍스트를 제공합니다. SVG를 인라인으로 여러 번 넣는 경우 title ID가 겹치지 않도록 바꿉니다.

밝은 지도 UI를 위한 표식입니다. 형태를 늘이거나 외곽 그림자·문자를 추가하지 않고 정사각형 비율을 유지합니다. 글꼴·외부 이미지·스크립트가 없어 별도 다운로드가 필요하지 않습니다.
