운영 사이트는 [Seoul Real Estate Map](https://seoul-elevation.vercel.app)입니다. `main`에 병합하면 검증 후 기존 Vercel 계정으로 자동 배포됩니다. 계정·환경변수·실패 확인 방법은 [자동 배포 문서](docs/DEPLOYMENT.md)를 참고하세요.

단지·실거래·관리비·정비사업 자료와 지형·건물을 함께 탐색하는 서울 부동산 지도입니다. 구축 과정에서 정리한 [부동산 데이터 지식 노트](docs/knowledge/README.md)에는 식별자와 연결 기준, 지도 숫자 해석, 출처·검증·갱신 방법을 담았습니다.

랜드마크·인프라·주거 모델 총 **113,123개**입니다. 기존 13,607개를 보존하고 서울도시공간포털의 대상 도형 131,618건을 전수 대조해 빌라·연립 74,203동, 아파트 5,143동, 주상복합 489동, 오피스텔 1,596동, 세부 유형 미상 공동주택 18,085동을 추가했습니다. 서울의 모든 실제 주거 건물이 확인됐다는 의미는 아니며, 중복·불명확한 도형의 제외 사유도 기록했습니다. 지역별로 필요한 모형만 불러옵니다. [이번 전수 조사·높이 근거·한계](docs/RESIDENTIAL_SURVEY.md), [이전 주거 모델](docs/RESIDENTIAL_MODELS.md), [공공시설·교량](docs/INFRASTRUCTURE_MODELS.md). 이 수치는 PR 브랜치 기준이며 운영 사이트 반영은 병합·배포 후 확인합니다.

지역별 원본 분할, 서비스 DB, 재업로드와 원격 실행 방법은 [Turso 운영 문서](docs/TURSO.md)를 참고하세요. 토큰과 원본 SQLite는 이 저장소에 포함하지 않습니다.

## 지도와 데이터

서울의 주택가·택지 주변에서 **원본 5m 등고선·표고점·건물 외곽선**을 아파트·정비사업·생활 인프라와 함께 살펴보는 웹 지도입니다. 처음 열면 **지형 4배 강조의 2.5D**로 시작합니다. 건물의 원본 높이와 외곽선 크기는 배율과 별도로 유지합니다.

## 부동산 데이터 지식

프로젝트를 만들며 정리한 [자료별 역할](docs/knowledge/data-sources.md), [단지·동·필지 연결 기준](docs/knowledge/identifiers-and-joins.md), [지형·높이·면적 읽기](docs/knowledge/reading-map-data.md)를 함께 공개합니다. 공개 자료를 조사하고 코드로 검증한 범위와 미확인 부분을 구분했습니다.

## 비행기 모드와 개별 건축 모델

상단 **비행기 모드**를 누르면 보고 있던 위치에서 서울을 날아볼 수 있습니다. Seoul Flight의 조종 로직을 이 지도의 실제 지형·건물 위로 옮겼습니다. W/S로 상승·하강, A/D로 선회하고 화면의 조종 버튼도 사용할 수 있습니다. Space/P는 일시정지, Esc 또는 **비행 종료**는 원래 지도 시점으로 돌아갑니다. 건물 충돌은 없는 자유 비행입니다. [조작·성능·구현 범위](docs/FLIGHT.md).

기존 Flight 랜드마크와 개별 재제작 모델은 저장소 이름 변경 후에도 유지합니다. 중명전, 국립현대미술관 덕수궁 서관, LG아트센터 서울·LG디스커버리랩을 추가해 현재 개별 검수한 GLB는 **30개**입니다. 이 수치와 전체 일반 도형 모델 수는 다릅니다. 사진·도면 근거, Blender 원본, 렌더와 한계는 [모델 검수 기록](docs/model-audit/README.md)에 있습니다.

## 현재 가능한 기능

- 서울 원본 등고선 8,570개·표고점 45,870개를 SQLite + RTree로 저장하고 화면 범위에 맞춰 조회
- 5/10/25m 높이 간격, 등고선·표고점·배경지도·보간 음영 표시 전환
- 고정 동네 바로가기·지역명 카드 없이 43,809개 등록 이름 검색, 위도·경도 이동
- 철도·지하철역 311개, 다리 원본 위치 552개(그중 모델 26개), 교차로 775개, 이름 있는 주거 영역 3,371개의 원본 위치를 화면에 맞춰 핀으로 표시
- 서울시 공동주택 원본 2,887개 보존, 아파트 핀 기준을 100세대 이상으로 확대하고 공식 세대수 표시; 새 GLB 1,514단지의 개별 동 연결에는 근접 추정이 포함됨
- 녹지·잔디·숲 구분과 숲 내부 장식 나무, Blender 빌딩 4종(롯데월드타워·63빌딩·N서울타워·트레이드타워)
- 압축 전송·화면 근처 모델 로딩·나무 계산 worker·영역 캐시·화면 선명도 조절
- 등록 이름이 있는 건물은 확대 시 이름 표시, 검색 결과에서 원본 건물 기록 확인
- 지도 위에서 건물·차도·보행로·장소 핀을 각각 켜고 끄기
- 차도 79,812선, 보행로 37,071선, 계단 3,034선을 원본 형상과 연한 색의 중심선 기호로 분리 표시
- 사람 1인칭에서만 선택적으로 표시하는 고정 크기 비교 모형: 사람 1.7m·승용차 길이 4.3m, 자동 이동 없음
- 지도 선택 시 가까운 **원본 표고점의 값과 선택 위치까지의 거리** 표시
- 원본 등고선 선택 시 해당 선의 높이 표시
- 아파트 단지 핀 선택 시 같은 단지코드로 연결된 K-apt 기본정보·한국부동산원 동정보·관리비 표시, 재건축·재개발 구역 도형 레이어(서울도시공간포털)
- 이름을 붙여 위치 저장·다시 열기·삭제, 브라우저를 새로 열어도 로컬 SQLite에 유지
- 2D / 실제 요철이 있는 2.5D 전환, 최대 줌 24·기울기 85도, 화면 높이 강조 1–8배
- 원본 길의 추정 지면 위 약 1.7m에서 보는 사람 1인칭 모드, 수동 앞뒤 3m 이동·좌우 회전과 이전 지도 시점 복원
- 보간을 뒷받침할 자료가 부족한 영역은 음영 또는 2.5D에서 회색 표시
- 작은 화면에서는 접을 수 있는 설정 패널
- 서울 25개 구의 건물 외곽선 **365,456동** 및 부분 도형 **1,684개**를 로컬 SQLite에 수록
- 모델 자산 113,123개: 세대수 하한 없는 주거 모델과 공식 도형 전수 조사 99,516동 추가, 공공시설 364개(학교 224·공공청사 140), 한강 교량 26개, 시청·문화시설·주요 회사 사옥 포함
- 대로 노면 6,894개 구간(437개 도로명), 철도 위치 기록 311개, 서울시 공식 버스 정류소 11,218개·따릉이 대여소 2,786개; 버스·따릉이 독립 표시와 출처 팝업
- 원본 높이가 있는 건물·부분만 입체 표시, 높이 미등록은 외곽선으로 표시
- 건물 선택 시 기록 높이·외곽선 면적·층수·출처·원본 식별자 확인, 아파트만 보기

**모든 건물의 실제 높이를 확보한 상태는 아닙니다.** 현재 Overture 2026-08-19.0 자료의 건물 365,456동 중 높이가 기록된 것은 **26,626동(7.29%)**입니다. 그 값도 OSM 기여자의 기록이며 독립적인 실측 검증은 하지 않았습니다. 영상에서 추출한 외곽선은 지붕 윤곽일 수 있어 지상 접지 면적과 다를 수 있습니다. 원본 DB의 높이 누락은 채우지 않습니다. 별도 GLB 모형에는 자료에 없는 높이와 외관을 추정한 부분이 있으며, 원본 건물 기록과 구분해 표시합니다. [인프라 모델의 추정 범위](docs/INFRASTRUCTURE_MODELS.md)를 참고하세요.

등고선은 건물 높이와 별개입니다. 공식 원본의 등고선 8,570개와 표고점 45,870개를 **전수 적재**했고, 원본 SHP/DBF를 직접 해석해 모든 좌표·높이가 DB와 일치함을 다시 확인했습니다. [전수 감사 결과](docs/CONTOUR_AUDIT.md). 이것은 원본의 모든 선·점을 보존했다는 뜻이며, 그 사이를 포함한 서울 모든 지점의 실측 고도를 확보했다는 뜻은 아닙니다. 2.5D 표면은 보간 결과입니다.

일반 주소 검색 API, 모든 아파트 단지와 개별 건물대장의 완전한 연결, 자전거 길찾기, 경로 단면도, Supabase 연결은 아직 포함하지 않았습니다. BrightData·카카오 키 없이 실행합니다.

## 건물 자료와 아파트 정보 연결

현재 컴퓨터에는 원본 압축 파일과 manifest를 `data/building-source/`에 보존했습니다. 원본 SHA-256을 확인하고 건물 DB를 재생성할 수 있습니다.

```sh
.venv/bin/python scripts/build_buildings.py --source-dir data/building-source
```

건물 도형을 축소하거나 사각형으로 바꾸지 않고 원본 Polygon/MultiPolygon과 내부 구멍을 유지합니다. 외곽선 면적은 EPSG:5186 평면 좌표계에서 계산한 수평 면적이며, 건축물대장 건축면적·대지면적·연면적·아파트 전용면적과 다릅니다. 지도에서는 동네 수준(줌 14 이상)에 건물을 표시하며, 많은 영역에서는 응답 개수를 제한하고 이를 화면에 알립니다.

부분 도형이 있는 건물의 부모 외곽선은 입체로 중복해서 올리지 않습니다. 부분별 높이가 없거나 상부 구조물의 높이 기준이 확인되지 않은 경우 외곽선으로 남깁니다. MapLibre의 건물 지붕은 지형 대표점에 올라가므로 넓은 건물·급경사에서는 접지 오차가 생길 수 있습니다. 일반 건물 도형은 실제 지하층·지붕 형상을 재현하지 않습니다. 별도 교량 GLB 26개에는 상판·교각·주탑 등을 단순화해 추가했습니다.

전체의 대장 높이 보강용으로 **국토부 GIS건물통합정보의 서울 전체 SHP**를 연결하는 가져오기 도구도 준비했습니다. [공공데이터포털은 이 자료의 비용을 무료로 안내](https://www.data.go.kr/data/15083092/fileData.do)합니다. 브이월드 다운로드에 로그인이 필요하여 공식 전체 파일은 아직 가져오지 않았습니다. [다운로드와 가져오기 안내](docs/OFFICIAL_BUILDINGS.md), [향후 아파트 단지·동·건물 연결 설계](docs/APARTMENT_DATA.md)를 참고하세요. 원본 건물 ID를 보존하지만 Overture ID와 건축물대장·단지 코드를 자동으로 같다고 간주하지 않습니다.

추가 조사로 서울시 **건축물대장 표제부 CSV 585,194행**을 공개 다운로드해 `data/sources/seoul-building-register-2026-09-08.csv`에 보존했습니다. 이 중 높이 양수는 329,438행이며, 잘못된 것으로 의심되는 1,000m 초과 값도 있어 양수 자체가 정확성을 보증하지 않습니다. CSV에는 좌표·도형이 없습니다. 이번 별도 GLB 조사에서는 공식 도형·도로명주소 DB와 주소·층수·사용승인연도를 대조해 71,452동에 대장 높이를 적용했으며, 원본 DB 높이는 수정하지 않았습니다. [연결 기준과 한계](docs/RESIDENTIAL_SURVEY.md). [CSV 감사 결과](docs/REGISTER_CSV_AUDIT.md).

브이월드 외에도 서울도시공간포털·S-MAP의 공개 건물 도형 6건을 키 없이 조회해 원본과 출처를 보존했습니다. 이 도형에는 주소와 건물관리번호가 있지만 높이는 없습니다. 대장과 대조해 같은 주소의 여러 동·구관과 신관·오래된 속성이 섞이는 사례를 확인했습니다. [공개 도형 조사](docs/PUBLIC_MAP_SOURCES.md), [585,194행 주소키 분석과 6건 대조](docs/REGISTER_JOINABILITY.md)에 결과가 있습니다. 당시에는 연결 후보를 검토한 단계였습니다. 이후 공식 도형 131,618건을 조사하고 조건이 맞는 건물의 별도 GLB에 높이를 연결했습니다. 원본 지도 DB 값은 유지합니다. BrightData 호출은 없었습니다.

2026-09-10에 아파트 관련 공개 자료 **48종**을 로그인·API 키 없이 받아 원본과 manifest를 `data/sources/`에 보존했습니다. K-apt 단지 위치·목록, 한국부동산원 단지 식별정보(기본·동·이력), 건축물대장 총괄표제부, 주택인허가 동별개요, 관리비, 실거래·전월세, 2025 공동주택 공시가격, SH·LH·HUG 단지 목록, 자치구 공동주택 현황, 정비사업 구역 도형, 도로명주소 건물DB 등입니다. 전부 `data/apartment_sources.sqlite`에 적재했고, 같은 단지코드·필지번호로만 연결표를 만들었습니다. 지도에는 세 가지를 연결했습니다. K-apt 단지 위치 보완, 단지 핀을 누르면 나오는 K-apt 기본정보·한국부동산원 동수와 최고 지상층수·최근 관리비 부과 합계, 켜고 끌 수 있는 **재건축·재개발 구역** 레이어입니다. 실거래·전월세·공시가격·건축물대장·주택인허가는 같은 필지번호(PNU)로 단지와 이어 팝업에 보여줍니다(실거래 2,774개 단지, 공시가격 2,837개 단지). 자치구 공동주택 현황·SH·LH 목록·주차면수·도로명주소 건물DB·건물에너지는 도로명주소 건물DB로 주소를 필지번호 하나로 확정한 경우만 단지에 이었습니다. 정비사업 사업장·도시정비 통계와 SH 임대 단지(상세 페이지 주소)도 같은 방식으로 이었습니다. 주소가 없는 HUG 분양 목록만 적재 상태입니다. [아파트 관련 공개 자료 목록](docs/APARTMENT_SOURCES.md), [적재 결과](docs/APARTMENT_SOURCES_IMPORT.md)를 참고하세요. VWorld GIS건물통합정보·건축HUB API·공시가격알리미처럼 로그인·키·캡차가 필요한 자료는 받지 않았습니다.

## 400세대 이상 단지 · 녹지 · 주요 빌딩

[서울시 공동주택 자료](docs/APARTMENTS_400.md)는 아파트·주상복합 400세대 이상 1,363개 중 1,359개의 위치를 연결했습니다. 서울시 좌표가 없거나 잘못된 단지는 같은 단지코드의 K-apt 위치로 보완했고, 4개는 다른 단지와 좌표를 공유해 표식을 보류했습니다. 분양·임대 등 관리단지 코드별 세대수이며 서로 합산하지 않습니다. 단지 위치와 세대수를 확보해도 개별 동의 실제 높이가 자동으로 확보되는 것은 아닙니다. 세대수 미등록이나 400 미만인 곳도 일반 이름 검색은 가능합니다.

[Blender 모델 4종](docs/CITY_MODELS.md)은 기존 서울 비행 프로젝트의 GLB를 실제 좌표와 공개 높이에 맞춰 사용합니다. 높이는 1배이고 외형 세부·평면 범위는 참고 재현입니다. 새 Blender 재수출은 macOS Metal 초기화 오류로 실패했으며, 기존 결과물을 SHA와 치수 검증 후 재사용했습니다. 도형 ID가 확인된 기존 입체만 대체하며 모델을 끄면 복원합니다.

[녹지](docs/GREENERY.md)는 원본 landcover 분류로 숲·잔디·공원을 구분합니다. 숲 안의 최대 240개 나무는 장식이며 개별 나무의 실제 위치·높이 기록이 아닙니다. 건물·차도·보행로·폴리곤 구멍을 피해 배치하고 작업 스레드에서 계산합니다. [성능 정책](docs/PERFORMANCE.md)에 압축·해상도·캐시와 검증 범위를 기록했습니다.

## 주요 장소와 차도·보행로

**사람 1인칭** 버튼은 주변 원본 길의 추정 지면 위 약 **1.7m** 시점을 준비합니다. 설정의 **거리 크기 가늠하기 → 사람 1인칭 예시**는 높이 기록이 있는 건물과 길을 함께 볼 수 있는 **행당동**으로 이동합니다. 지형은 **1배**로 두며, **지도 시점**을 누르면 진입 전 카메라·2D/2.5D 모드·강조 배율을 복원합니다. 최대 줌은 24, 기울기는 85도이며 1인칭의 실제 줌은 화면 크기에 따라 달라집니다.

자동으로 걷는 사람·달리는 차량·땀 효과는 제거했습니다. 일반 지도에서는 크게 확대해도 사람·차량 모형과 이 기능의 경로 요청이 생기지 않습니다. 1인칭의 **크기 비교 모형 표시**를 켜면 실제 길 위에 사람 최대 1개·승용차 최대 1개의 고정 예시를 놓습니다. 사람 키 1.7m, 승용차 길이 4.3m·폭 1.8m·높이 1.5m이며 실제 사람·차량의 관측 위치가 아닙니다. 길 자료나 보이는 자리가 없으면 해당 모형은 표시하지 않습니다. [사람 1인칭과 정적 모형](docs/MOBILITY.md).

앞뒤 3m 이동·좌우 회전은 사용자가 버튼으로 조작합니다. 같은 장면의 모형 좌표는 고정되며 시간에 따라 움직이지 않습니다. 드래그·휠·지도 확대 버튼·외부 카메라 API를 쓰면 길 고정을 해제하고 비교 모형을 숨깁니다. 이때 현재 카메라와 지형 1배를 유지하며, 늦은 지형 갱신도 수직 높이만 보정해 확대 동작을 되돌리지 않습니다.

대로는 원본 중심선과 추정 폭에 맞춘 어두운 노면을 추가했습니다. 나머지 차도 중심선은 연한 회색, 보행로·횡단선은 연한 녹회색, 계단은 연한 베이지색입니다. 로컬 중심선 폭은 확대해도 차도 **최대 12px**, 보행로 **3px**, 횡단선·계단 **3.5px**를 넘지 않습니다. 이는 지도 기호이며 실제 노폭을 미터 단위로 추정한 면이 아닙니다. 줌 **19 이상·기울기 75° 이상**에서는 등고선·표고점과 라벨, 선택 위치 연결선, 보간 음영, 건물 외곽선을 잠시 숨깁니다. 로컬 도로 자료가 준비되면 저해상도 배경 도로와 도로 이름도 숨기며, 일반 화면으로 돌아가면 원래 표시 설정을 적용합니다.

정적 모형은 카메라 진입 때 받은 경로를 재사용하고 자체 네트워크 요청·애니메이션 루프 없이 지도 변화에 맞춰 그립니다. 발·차량 바닥은 현재 지면에 맞추며 지형·일반 건물에 가려진 앵커는 보수적으로 숨깁니다. Blender GLB까지 정확한 깊이 판정을 하는 방식은 아닙니다. 1.7m 카메라도 보간 지면을 기준으로 한 설정이며 현장 측량 높이를 뜻하지 않습니다. 높은 기울기의 근접 화면에서는 상세 자료를 중심 주변 **600m 전체 정사각형**에서 조회합니다.

주요 주거지 검색에서는 헬리오시티, 파크리오, 잠실 엘스·리센츠, 반포자이, 래미안원베일리, 타워팰리스, 서울숲트리마제, 갤러리아포레, 아크로서울포레스트, 한남더힐을 원본 주거 영역으로 확인했습니다. 단지 핀은 주변의 이름 없는 개별 동에 공식 이름·높이를 자동 대입하지 않습니다. 핀과 건물 도형은 독립적으로 표시합니다.

장소·도로의 OSM 원본 기준은 **2026-06-01**이고, 2026-09-08에 받았습니다. 이름 검색 43,809개는 중복을 정리한 원본 객체 수이며 완전한 주소 사전이나 모든 서울 건물 목록이 아닙니다. 건물 이름은 그중 35,745개입니다. 주거 영역은 아파트 외의 이름 있는 주거지를 포함합니다.

보행로 37,071선에는 별도로 등록된 보도 8,343선과 횡단보도 7,156선, 일반 보행로·공유 자전거길 등이 포함됩니다. 차도의 `sidewalk` 속성만 보고 옆에 가상의 인도를 만들지 않습니다. 비공개·통행 제한 속성도 원문에 남아 있어 길찾기나 보행 가능 보증 자료로 볼 수 없습니다. 원본 725,816좌표를 DB와 비교해 불일치가 없음을 확인했습니다. 자세한 범위·출처는 [도로 자료](docs/ROAD_SOURCES.md), [장소 자료](docs/PLACE_SOURCES.md)에 있습니다.

## 이 컴퓨터에서 실행

Node.js와 프로젝트 Python 환경이 준비되어 있습니다.

```sh
cd seoul-real-estate-map
npm run build
npm start
```

개발할 때는 `npm run dev`를 사용합니다. 기본 안내는 JS/CSS/GLB 사전 압축 파일을 제공하는 운영 빌드입니다.

- 화면: <http://127.0.0.1:4173>
- 로컬 API: <http://127.0.0.1:8791/api/health>
- `Ctrl+C`로 웹 서버와 API를 함께 종료합니다.
- 두 포트 중 하나가 이미 사용 중이면 중복 실행하지 않습니다.
- API는 **127.0.0.1에만** 열립니다. 휴대폰이나 다른 컴퓨터로 공개한 상태는 아닙니다.

지형·건물·장소 검색·상세 도로 DB는 로컬에 있습니다. 강·공원·지명·도로 배경은 무료 OpenFreeMap 벡터 타일, 숫자 라벨은 MapLibre 데모 글꼴 서비스를 사용합니다. 배경에 별도 건물 레이어를 넣지 않아 건물 표시를 끄면 건물 도형과 이름이 함께 사라집니다. 배경 차도와 로컬 차도도 같은 토글로 숨깁니다. 네트워크가 없어도 로컬 자료는 조회되며 온라인 배경/글꼴만 사용할 수 없을 수 있습니다.

## 다른 컴퓨터에서 처음 준비

Node.js 22.12+ 또는 최근 LTS, Python 3.12+, `uv`가 필요합니다. Python 3.12로 검증했습니다.

```sh
git clone https://github.com/minwoo19930301/seoul-real-estate-map.git
cd seoul-real-estate-map
npm ci
uv venv .venv --python 3.12
uv pip install --python .venv/bin/python -r requirements.txt
.venv/bin/python scripts/download_source.py
.venv/bin/python scripts/build_database.py --source data/seoul-contours.zip
.venv/bin/python scripts/build_terrain.py --source data/seoul-contours.zip --maxzoom 14
npm run dev
```

위 명령은 지형 자료를 준비합니다. 장소·도로 DB 재생성은 [장소 원본 및 검색](docs/PLACE_SOURCES.md), [차도·보행로 원본](docs/ROAD_SOURCES.md)의 명령을 따릅니다. 건물은 별도로 서울 Overture 원본 패키지를 준비해 `build_buildings.py`에 전달하거나 공식 SHP를 가져와야 합니다. 건물 DB가 없을 때에도 지형 기능은 실행되며 화면에 자료 미구축 상태를 알립니다.

공식 지형 다운로드의 SHA-256을 확인합니다. 공급 파일이 바뀌면 조용히 다른 버전을 사용하는 대신 중단하므로, 새 파일의 기준 시점·구조·조건을 검토하고 갱신해야 합니다. 원본 ZIP·압축 건물 원본·생성 DB·지형 PNG·가상환경은 Git에서 제외합니다.

## 2.5D와 고도 읽기의 의미

2.5D는 평면 지도를 기울이기만 한 화면이 아닙니다. 원본 등고선을 30m 간격으로 표본화하고 표고점과 합친 **726,207개 보간 제약점**으로 선형 TIN을 구성했습니다. 이 표면을 z10–14의 Mapbox RGB 지형 타일 **818개**로 만들었습니다. 각 타일의 높이 인코딩 간격은 0.1m이지만 **자료의 실제 정확도가 0.1m라는 의미가 아닙니다.**

원본의 수직 기준과 현장 오차는 아직 독립적으로 검증하지 않았습니다. 공사 이후 지면, 옹벽, 계단, 교량 상판과 건물 높이를 정밀하게 복원한 모델도 아닙니다. 하천·자료 공백·외곽에는 보간 또는 화면 연속성을 위한 높이 연장이 포함됩니다. 별도 유효성 마스크와 회색 표시가 이를 구분합니다. 회색이 아닌 영역도 모두 **추정 지형**입니다.

높이 조회는 2.5D 렌더링 결과를 읽지 않고 SQLite의 원본 표고점을 조회합니다. 선택 지점에서 1km 이내의 최근접 점이 없으면 값이 없다고 표시합니다. 화면 높이를 4배로 강조해도 원본 표고점의 숫자는 변하지 않습니다. 원본 표고점의 소수 자릿수는 기록된 값을 보존하기 위한 것이며 그만큼의 정확도를 보증하지 않습니다.

원본 자료 범위는 데이터의 사각형 extent입니다. 정확한 서울 행정경계로 자르지 않았습니다. 낮은 줌에서는 높이 간격을 10/25m로 늘리고 선 모양을 단순화하며, 표고점이 겹치면 일부만 표시합니다. 화면과 API 메타데이터에 해당 상태를 표시합니다.

| `public/data/terrain.json` | 보간 방법·원본 SHA·유효 범위·타일 목록 | 생성 시 갱신 |

SQLite 원본은 API에서 읽기 전용으로 엽니다. DB를 재생성한 후에는 실행 중인 API도 재시작해야 합니다. Supabase에 실제 적재한 상태는 아닙니다. 현재 로컬 API는 영역별 GeoJSON을 전송하며, 외부 서비스 단계에서는 정적 벡터 타일과 PostGIS를 검토할 수 있습니다.

## 검증과 빌드

```sh
.venv/bin/python -m unittest discover -s tests -p 'test_*.py' -v
node --test tests/*.test.mjs
npm run build
# npm run dev가 실행 중일 때, 설치된 Chrome으로 실행
npm run test:e2e
```

검증 내용: 음수 높이 보존, 실제 원본 최근접 점/거리, 범위 잘라내기, 잘못된 입력, 원본 쓰기 차단, 북마크 영속성, RGB 높이 왕복, 지형 타일 경계와 원본 보간 표면 일치, 자료 공백 표시용 타일, 브라우저 모드 전환/조회/모바일/외부 연결 실패.

사람 1인칭·정적 크기 비교 모형 변경은 Node 39개와 Chrome 전체 26개 검사를 통과했습니다. 이전 자동 이동의 측정 기록은 별도로 보존합니다. 변경별 실제 검사 결과는 [VERIFICATION.md](VERIFICATION.md)에서 확인합니다.

빌드 결과만 사용하는 경우에는 아래 서버 하나로 화면과 API를 함께 제공할 수 있습니다.

```sh
npm run build
.venv/bin/python -m server.app --port 8791 --static-dir dist
```

이 경우 화면도 <http://127.0.0.1:8791>에서 열립니다. 이미 API 서버가 실행 중이면 먼저 종료한 후 실행합니다.
